# About

{{ site.brand }}は、高周波コネクタと同軸ケーブルアッセンブリを、公開情報の範囲で読むための静的な学習サイトです。{{ site.brand_note }}

いまの表示名は「{{ site.brand }}」、タグラインは「{{ site.tagline }}」です。名前を変えるときは、設定の `brand` を書き換えます。ヘッダー、フッター、ブラウザのタイトルが揃って変わります。

## 何を扱うか

製品の単位は、コネクタ単体ではなく、高周波コネクタ＋同軸ケーブルアッセンブリです。通信、車載レーダー、衛星、半導体の試験と治具、計測器という場面で、なぜ精密で、なぜ多品種・小ロットになりやすいのかを、学びの側から整理します。

掲載言語は日本語です。

## 何を扱わないか

- 個別製品の在庫、価格、保証値
- 非公開の図面や、社内の採算、運営上の課題
- 職の募集や、学習課程の申込
- 系列ごとのトルク表や、そのまま製造に使える手順書

周波数と系列の数字は、公開情報にもとづく目安です。境界の確認は、参照する規格と、製品側の仕様を見てください。
