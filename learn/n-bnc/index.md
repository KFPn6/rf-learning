# N型とBNCの違いと使い分け

N 型と BNC は、どちらも高周波の同軸コネクタです。結合が違います。IEC 61169-16:2006 の題は、ねじ結合、特性インピーダンス 50 Ω（75 Ω）、type N です。IEC 61169-8:2007 の題は、バヨネット、特性インピーダンス 50 Ω、type BNC です。Rosenberger の RPC-N の技術資料は、結合ねじを 5/8-24 UNEF と書きます。BNC の資料は、二本のスタッドです。Amphenol のカタログは、メス側の二つのラグを、結合ナットの約四分の一回転で嵌合する、と書きます。ねじの山と、スタッドは、掛かり合う相手ではありません。系列をまたぐときは、変換アダプタです。

ここにある数字は、公開の規格のプレビューと、メーカーの技術資料、計測器メーカーのアプリケーションノートから取った学習用の目安です。個別の製品が保証する値ではありません。同じ名前でも、資料が複数の周波数と、複数の電力と、複数のトルクを置きます。平均して一つの上限にはしません。

系列の早見は [コネクタの種類]({{ '/learn/connector-types/' | relative_url }}) です。同じねじ同士の SMA との呼びの違いは [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) です。SMA の 1/4-36 と、このバヨネットの使い分けは [SMAとBNC]({{ '/learn/sma-bnc/' | relative_url }}) です。同じ 6.5 mm の呼びでねじにした TNC は [BNCとTNC]({{ '/learn/bnc-tnc/' | relative_url }}) です。どちらもねじである N 型と TNC は [N型とTNC]({{ '/learn/n-tnc/' | relative_url }}) です。N 型の 50 Ω と 75 Ω の見分けと、誤嵌合の注意は [N型の50Ωと75Ω]({{ '/learn/n-50-75/' | relative_url }}) です。BNC の 50 Ω と 75 Ω は [BNC の 50 Ω と 75 Ω]({{ '/learn/bnc-50-75/' | relative_url }}) です。このページは、両方の系列に両方があることと、その導線にとどめます。宅内のねじの 75 Ω は [F型コネクタ]({{ '/learn/f-type/' | relative_url }}) です。上限を平均しない読み方は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。

7 mm と 6.5 mm は、規格の題が置く外導体内径の呼びです。胴の外径の公差として、このページが読み直した数字ではありません。4、1.5、11、12、18 を、一つの N 型の上限にはしません。1、4、10、11 を、一つの BNC の上限にはしません。5000、2000、600、150 も、一つの電力にはしません。図面は転載していません。

## ねじと、バヨネット

IEC 61169-16:2006 の適用範囲は、ピンとソケットの高周波同軸コネクタで、結合はねじ、用途の文は低から中の電力です。通称は type N、と書きます。50 Ω には三つの版があり、互いに嵌合しうる、と続きます。grade 2 は汎用で、およそ 12 GHz まで、と書きます。grade 1 の一部は 18 GHz まで、grade 0 も 18 GHz まで、と書きます。Webstore の公開案内は、題と、詳細仕様を書くための規則と、低から中の電力と、50 Ω の三つの版が互いに嵌合できること、までです。GHz の文と、5/8-24 の文字は、その案内にはありません。周波数は、開いたプレビューの適用範囲で置きます。

ねじの呼びは、Rosenberger の RPC-N 50 Ω の技術資料で置きます。プラグの F は 5/8-24UNEF-2B、ジャックの F は 5/8-24UNEF-2A です。2B は内ねじ、2A は外ねじの等級です。プラグの G は hex 19 です。ジャックの G は、その表にありません。開いたプレビューのピン中心の表の注も、5/8-24 UNEF-2B、と書きます。表のほかの寸法は、このページでは転載していません。5/8 インチは 0.625 インチで、0.625 × 25.4 = 15.875 mm です。これはねじの呼び径の換算であり、結合ナットの二面幅ではありません。hex 19 とも、別です。

IEC 61169-8:2007 の適用範囲は、低電力で、着脱が速い用途、結合はバヨネット、通称は type BNC、と書きます。外導体内径の呼びは 6.5 mm（0.256 in）です。Webstore の公開案内も、クイックな着脱と、バヨネット、までです。開いたプレビューの適用範囲に、GHz の数字はありません。IEC は小数点をコンマで書きます。題の 6,5 mm と 0,256 in を、地の文では 6.5 mm、0.256 in とします。N 型の題の 0,276 in も、地の文では 0.276 in です。

Amphenol のカタログは、メス側に二つのバヨネットのラグがあり、結合ナットの約四分の一回転で嵌合する、と書きます。仕様表の結合は、2-stud bayonet coupling です。Rosenberger の製品案内は、二本のスタッドのバヨネットで、容易で速く、確実な接続、と書きます。四分の一回転を、ねじの山が何回転も進む締め方には読みません。

ナットの開口も、一つの寸法にはしません。Rosenberger のプラグの G は hex 19 です。Rohde & Schwarz の 1MA99 のトルクの表は、N-Type のナット開口を 3/4 インチ、20 mm と書きます。3/4 インチ × 25.4 = 19.05 mm です。この計算は、インチの開口の換算です。同じ行が 20 mm と書くことと、19.05 を、一つの開口にはしません。hex 19 を、その 20 mm の更新にも読みません。hex 19 を、N のジャックや、ほかのメーカーの全部へは写しません。

## 周波数の目安

周波数は、学習用の目安です。製品が保証する上限ではありません。

N 側で、このページが並べる行は次です。IEC 61169-16:2006 の適用範囲は、grade 2 をおよそ 12 GHz、grade 1 の一部を 18 GHz まで、grade 0 を 18 GHz まで、とします。Webstore の公開案内に、この GHz の文はありません。Rohde & Schwarz の 1MA99 は、タイプ N（50 Ω）の最大周波数を、通常型 11 GHz、精密型 18 GHz、と書きます。同じノートの図は、市販のコネクタの動作周波数の例として、Type N を 11 GHz、Precision N を 18 GHz に置きます。英語版（2015 年 4 月、1MA99_2e）と、日本語版（2012-12-12、Version 1.0）で、この 11 と 18 の並びは同じです。二つの版の全文が同一だとは、このページでは確認していません。Rosenberger の RPC-N の製品案内は、50 Ω を 18 GHz まで、75 Ω を 4 GHz まで、とします。技術資料の 50 Ω の行は DC to 18 GHz です。Radiall は、標準の N を DC–11 GHz、N 18 GHz を DC–18 GHz、75 Ω を DC–1.5 GHz とします。1MA99 は、75 Ω の上限を 4 GHz、とも書きます。4 と 1.5 を、一つの 75 Ω の上限にはしません。4、11、12、18 を平均しません。

BNC 側の行は次です。同じ 1MA99 の図は、BNC を 4 GHz の例に置きます。日本語版の図のラベルも、BNC を 4 GHz の側に置きます。BNC だけの節は、このノートにはありません。図の 4 を、節で説明された上限には読みません。Rosenberger は、50 Ω の最大を 10 GHz、最適を 4 GHz、75 Ω の最大を 4 GHz、最適を 1 GHz とします。Amphenol のカタログの 50 Ω の説明は、11 GHz まで動作するよう設計され、4 GHz まで低い反射が典型、と書きます。同じカタログの 50 Ω の仕様表は、周波数範囲を 0–4 GHz、低い反射、と書きます。11 と、表の 0–4 は、別の文です。75 Ω の節は、Type 1 を 4 GHz まで低い VSWR、Type 2 を 1 GHz まで低い反射、と分けます。仕様表の周波数範囲は 0–4 GHz です。1、4、10、11 を平均しません。図の 4 を、カタログの 11 の更新には読みません。カタログの 11 を、Rosenberger の最適 4 の更新にも読みません。

1MA99 の図の前の文は、より小さい同軸の形状ほど、使える上限が高くなる例がある、と書きます。N の題の 7 mm と、BNC の題の 6.5 mm は、この文の大小の側にあります。径が小さい方が、その製品の定格まで自動で伸びる、とはその文は書いていません。同じノートは、具体の型の性能は、必ずメーカーに確認する、と書きます。カットオフの計算へ寸法を入れる読み方は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。このページは、その計算を N 型と BNC の保証値にはしていません。

## 電力の目安

電力も、資料の文のまま置きます。ワットを平均して、一つの上限にはしません。

IEC 61169-16 の適用範囲は、低から中の電力、と書きます。ワットの数字は、その文にはありません。IEC 61169-8 の適用範囲は、低電力、と書きます。ワットの数字は、その文にもありません。低から中、と、低電力、を一つの比にはしません。

Radiall の N の導入は、High power rating、と箇条に置きます。ワットの数字は、その箇条にはありません。同じ資料の N 18 GHz の節は、中から高の電力と、精密なマイクロ波の測定器に向く、と書きます。低から中、と、中から高、を一つの電力にはしません。N 18 GHz の特性の行は、海面で、ピーク電力 5000 W です。平均電力は、海面、25 °C で、0.1 GHz が 2000 W、1 GHz が 600 W、10 GHz が 150 W です。5000 と 2000 と 600 と 150 を、一つの N 型の定格にはしません。標準の N の特性のページに、このワットの行はありません。無い行を、5000 W で埋めません。

Rosenberger の RPC-N の技術資料に、電力の行はありません。無い行を、Radiall の 5000 W で埋めません。開いた BNC のカタログの仕様表は、電圧を 500 V peak、耐電圧を 1500 V rms、と書きます。75 Ω の仕様表は、電圧を 500 V rms、耐電圧を 1500 V rms、と書きます。電圧の行を、ワットには読み替えません。同じカタログの終端キャップに、1/2 W や 1 W の抵抗の行があります。抵抗の定格を、コネクタの電力には読みません。Rosenberger の BNC の製品案内にも、ワットの行はありません。

## インピーダンス

N 型にも、BNC にも、50 Ω と 75 Ω があります。このページは、そこまでです。

IEC 61169-16 の題は、50 Ω（75 Ω）です。Rosenberger の RPC-N の製品案内は、50 Ω と 75 Ω の両方を置きます。Radiall も、50 Ω と 75 Ω の両方を置きます。ピンの大小、ねじが共通でも嵌合してはいけないこと、資料で分かれる上限の読み分けは [N型の50Ωと75Ω]({{ '/learn/n-50-75/' | relative_url }}) です。

IEC 61169-8 の題は 50 Ω です。開いたプレビューの目次は、75 Ω の界面寸法を付録に置く題を載せます。付録の本文は、開いた 15 ページの範囲にはありません。Rosenberger の製品案内は、50 Ω と 75 Ω の両方を置きます。Amphenol のカタログも、50 Ω と 75 Ω を置きます。嵌合ピンの径、誘電体の見え方、混ぜたときの反射は [BNC の 50 Ω と 75 Ω]({{ '/learn/bnc-50-75/' | relative_url }}) です。

境目の反射を欄へ入れるなら [電卓]({{ '/learn/calculator/#reflect' | relative_url }}) です。その計算を、ねじとバヨネットの違いを表す数字には使いません。同じ 75 Ω でも、宅内のねじの F 型は別の界面です。[F型コネクタ]({{ '/learn/f-type/' | relative_url }}) です。

## 大きさと、屋外と、着脱の速さ

大きさ、屋外、着脱も、資料の文のまま置きます。一つの「N 型は屋外、BNC は室内」にはまとめません。

外導体内径の題は、N 型が 7 mm、BNC が 6.5 mm です。これは胴の外径ではありません。1MA99 は、タイプ N を、耐久性があり、耐候性があり、中サイズ、と書きます。Amphenol のカタログは、BNC を、小型の、着脱が速いコネクタ、と書きます。7 mm と 6.5 mm の差を、中サイズと小型の測定結果には読みません。

屋外の語も、資料で分かれます。1MA99 の耐候性は、タイプ N を開発したときの要求の文です。すべての個体が、ある IP 等級だ、とは書いていません。Radiall の複合材料のレセプタクルは、屋外での腐食の可能性を除く、と書きます。複合材料の一文を、真鍮の N 型全体の耐候には読みません。Amphenol の BNC の仕様表は、Weatherproof の行を、クランプはクランプガスケット、圧着は熱収縮チューブ、と書きます。注は、これらの特性は典型値で、すべてのコネクタには当てはまらない、です。この行を、BNC は屋外に向かない、という順位には読みません。屋外で使う一本は、その図面のシールを見ます。

着脱の速さは、結合の文で分かれます。BNC は、IEC がクイックな着脱、Amphenol が約四分の一回転、Rosenberger が容易で速い、と書きます。N 型は、ねじです。1MA99 の取り扱いの節は、規定のトルクまで校正済みのトルクレンチで締める、と書きます。四分の一回転の手順を、トルクレンチの折れる位置には読みません。逆も同じです。

## 用途の置き場所

用途も、資料の文のまま置きます。一つの「N 型は通信、BNC は映像」にはまとめません。置き場所の目安は、その文を読んだあとの案内です。規則ではありません。

Radiall の N の用途の列には、無線通信、民生と軍用の無線機器、対抗手段、海軍、産業があります。低い相互変調の節は、基地局、と書きます。N 18 GHz の節は、中から高の電力と、精密なマイクロ波の測定器、と書きます。1MA99 は、測定機器で使う同軸コネクタの選定と取り扱いの案内です。タイプ N の節は、その案内の中にあります。Rosenberger の RPC-N の用途は、50 Ω で 18 GHz まで、75 Ω で 4 GHz までの精密測定、セミリジッドとマイクロ波部品、航空宇宙向けの品種、です。屋外の基地局だけ、とは書いていません。

IEC の BNC は、低電力で、着脱が速い用途、と書きます。Rosenberger は、主に実験室、データシステム、通信、と書きます。用途の列には、ラジオ、映像、音声、オシロスコープと計測器の実験室、があります。Amphenol のカタログの用途の列には、アンテナ、計測器、オシロスコープ、ネットワークアナライザ、放送（75 Ω）、無線、基地局、があります。75 Ω の節は、放送と CATV、と書きます。実験室という語が N 型のノートと BNC のカタログの両方に出ても、結合は別のままです。基地局という語が両方に出ても、同じです。

読むときの目安は、次です。N 型は、通信、屋外、比較的高い電力、一部の計測、に置かれやすい、と資料の列が並びます。BNC は、着脱が多い場所、計測器、映像、に置かれやすい、と資料の列が並びます。カタログが両方にアンテナや基地局や計測を書くので、系列の名前だけで注文先は決まりません。図面の結合と、その製品の行を見ます。

## トルク

N 型の資料は、締付トルクを数字にします。BNC の資料は、バヨネットの回転と、掛け外しの上限を書きます。推奨のレンチ設定として、一つの N·m にはしません。

Rosenberger の RPC-N の技術資料は、推奨を 0.70–1.10 N·m、結合の試験トルクを 1.70 N·m とします。1.70 を、毎日のレンチ設定には読みません。1MA99 の表は、N-Type を 13.3 lb-inch、1.5 N·m、ナット開口 3/4 インチ、20 mm とします。注は、表の値はローデ・シュワルツが供給するコネクタ向けで、SMA は除く、と書きます。1.5 を、0.70–1.10 の更新には読みません。

Radiall の標準の N の推奨は、手締めで 40–60 N·cm、指定のプライヤで 130 N·cm（11.45 inch-pounds）、指定のトルクレンチで 170 N·cm（14.96 inch-pounds）です。証明トルクは 170 N·cm です。N 18 GHz の推奨は 160 N·cm（14 lbf·in）です。40–60 と 130 と 160 と 170 を、一つの N·cm にはしません。N·cm を、このページで N·m に換算して、Rosenberger の 0.70–1.10 や、1MA99 の 1.5 の代わりにはしません。同じ標準の N の表は、掛け外しのトルクを 6.6 N·cm 以下、とも書きます。6.6 は、推奨の締付ではありません。

BNC で確認できた数字は、別の種類です。IEC 61169-8 のゲージの節は、ピンコネクタのバヨネットを掛け外しするトルクは 0.25 N·m を超えない、と書きます。同じ節は、長手方向の力は 20 N を超えない、とも書きます。これは、掛け外しに要するトルクと力の上限です。推奨の締付トルクとして 0.25 N·m をレンチに設定する、という文ではありません。Amphenol の仕様表に、嵌合トルクの行はありません。結合の欄は、二本のスタッドです。N 型の 0.70–1.10 N·m を、四分の一回転へは使いません。0.25 N·m を、N 型の推奨の代わりにも使いません。

技術資料の末尾は、個々の値は用途、設計、ケーブル、組立、作業によって異なりうる、と書きます。上の幅を、すべての個体の設定値には読みません。

締付の残りの読み方は [コネクタの取り扱い]({{ '/learn/connector-care/' | relative_url }}) と [数値早見]({{ '/learn/quick-reference/' | relative_url }}) です。

## 見分けのポイント

見るのは、ねじを回し続けるナットか、スタッドが約四分の一回転で掛かるか、です。

指で回し始めて、山が噛み合わない相手は、その対ではありません。金色に見えること、白い樹脂が見えること、全体が大きいことは、N 型と BNC を分けません。中心がピンか穴かだけでも、決まりません。外導体内径の題は、7 mm と 6.5 mm で違います。目視の太さを、その呼びの測定にはしません。

ねじがあることだけでも、N 型とは決まりません。SMA は 1/4-36、TNC は 7/16-28 です。5/8-24 のナットは、1/4-36 にも 7/16-28 にも進みません。読み分けは [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) と [BNCとTNC]({{ '/learn/bnc-tnc/' | relative_url }}) と [N型とTNC]({{ '/learn/n-tnc/' | relative_url }}) です。メートルねじの type 7-16 も、別の呼びです。[N型と7/16]({{ '/learn/n-7-16/' | relative_url }}) です。M20×1 の 4.3-10 も、別の呼びです。[N型と4.3-10]({{ '/learn/n-43-10/' | relative_url }}) です。F 型のねじも、別の呼びです。[F型コネクタ]({{ '/learn/f-type/' | relative_url }}) です。

50 Ω か 75 Ω かは、ねじが見えること、スタッドが見えることだけでは決まりません。N 型でそれをどう読むかは [N型の50Ωと75Ω]({{ '/learn/n-50-75/' | relative_url }})、BNC でそれをどう読むかは [BNC の 50 Ω と 75 Ω]({{ '/learn/bnc-50-75/' | relative_url }}) です。

## 直接は嵌合しない

5/8-24 の山と、二本のスタッドは、掛かり合う相手ではありません。山が掛からないところから、力でねじを作りません。スタッドの溝へ、N 型のナットを押し込みません。

系列をまたぐときは、変換アダプタです。1MA99 は、違う型を一つの系で使うときは、周波数範囲が最も低い型が、系の周波数範囲を決める、と書きます。アダプタ自身の行も、別に見ます。両側のうち高い方まで使える部品だ、とは、その文は書いていません。ケーブル側で届かないこともあります。読み方は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。開いた BNC のカタログのアダプタの節は、BNC 同士の中継です。N 型への型番は、その節にはありません。無い型番を、このページでは作りません。

## 選定するときに見ること

- 図面で、N 型か BNC か、50 Ω か 75 Ω か、プラグかジャックか、を見ます。大きい同軸、という一語では注文しません。N 型の 50 Ω と 75 Ω は [N型の50Ωと75Ω]({{ '/learn/n-50-75/' | relative_url }})、BNC の 50 Ω と 75 Ω は [BNC の 50 Ω と 75 Ω]({{ '/learn/bnc-50-75/' | relative_url }}) です。
- 周波数は、資料の行のまま置きます。N 型は、IEC のおよそ 12 GHz と 18 GHz、1MA99 の 11 GHz と 18 GHz、図の 11 GHz と 18 GHz、RPC-N の 18 GHz と 4 GHz、Radiall の 11 GHz と 18 GHz と 1.5 GHz、1MA99 の 75 Ω の 4 GHz です。BNC は、図の例の 4 GHz、Rosenberger の 1 GHz、4 GHz、10 GHz、カタログの 4 GHz と 11 GHz です。
- 電力は、IEC の低から中と、低電力、を一つの比にはしません。ワットが読めたのは、Radiall の N 18 GHz の行です。ピーク 5000 W、平均は 0.1 GHz で 2000 W、1 GHz で 600 W、10 GHz で 150 W です。標準の N と、RPC-N と、開いた BNC の資料に、その行はありません。
- 結合は、5/8-24 のねじか、二本のスタッドの約四分の一回転か、です。直接はロックしません。変換アダプタは、両端の系列と、アダプタ自身の周波数と、両端の締め方をセットで見ます。
- 締付は、端の系列の行です。0.70–1.10 N·m、1.5 N·m、1.70 N·m、40–60 N·cm、130 N·cm、160 N·cm、170 N·cm を、一つの値にはしません。BNC の 0.25 N·m は、掛け外しがそれを超えない、というゲージの文です。四分の一回転の推奨トルクには読みません。
- 屋外は、耐候性という語だけでは決めません。シールの有無は、その製品の図面です。着脱の回数が多い場所では、バヨネットの文を先に見ます。それだけで、周波数と電力の行は決まりません。
