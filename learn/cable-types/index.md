# ケーブルの種類

高周波のアッセンブリで名前の出やすい同軸ケーブルを、インピーダンス、誘電体、損失の傾向、よくある用途で並べます。数字は、メーカーの整理表とデータシートから取った学習用の概数です。長さ、周波数、温度、版で変わります。個別の製品が保証する値ではありません。実際の値は、各メーカーのデータシートが定めます。

RG の番号は、同じ呼びでも中心導体や外被が分かれることがあります。このページの RG-58、RG-316、RG-142、RG-402、RG-405 は、Times Microwave Systems が MIL-C-17（現在の仕様書の呼びは MIL-DTL-17）を整理した表の、M17/28、M17/113、M17/60、M17/130、M17/133 の行です。LMR-400 は、同社の低損失フレキシブルの製品系列であり、軍用の RG 番号ではありません。ハンドフォーマブルと位相安定は、一つの呼びに固定せず、データシートのある一例で中身を見ます。

コネクタの系列は [コネクタの種類]({{ '/learn/connector-types/' | relative_url }})、断面の見方は [入門]({{ '/learn/beginner/' | relative_url }}) です。特性インピーダンスが径と比誘電率でどう決まるか、50 Ω と 75 Ω の読み分けは [特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) です。ケーブルをコネクタ、ブーツ、ラベルと組んだときの構成、長さ、曲げは [アッセンブリの構造と製作工程]({{ '/learn/assembly-basics/' | relative_url }}) です。減衰の単位と、長さ・周波数の計算は [同軸ケーブルの損失]({{ '/learn/cable-loss/' | relative_url }}) です。反射との切り分けは [VSWR とリターンロス]({{ '/learn/vswr-return-loss/' | relative_url }}) です。

dB/m は、資料の dB/100 ft を 100 ft = 30.48 m として換算した概数です。typical は、その整理表が「典型」として置いた値です。規格の最大とは別です。同じ呼びでも、最大の書き方はメーカーの整理で違います。下の各節に、換算前の数字を残してあります。

1 GHz 付近の typical で損失が小さい側から並べると、LMR-400（900 MHz の掲載値）、RG-402、ハンドフォーマブルの 0.141 インチ相当、RG-142、RG-58、RG-405、RG-316 です。RG-58 の規格上の最大は約 0.92 dB/m で、typical の並びとは別に大きくなります。位相安定の試験用ケーブルは、この並びに入れていません。

損失は、太さ、誘電体、外部導体（編組か金属管か）で変わります。同じ構造なら細い方が損失は大きくなりやすいです。RG-316 がこの表で大きい側なのは、外径が約 0.098 インチと細いためです。LMR-400 が小さい側なのは、外径約 0.405 インチで、誘電体が発泡だからです。

## RG-58

フレキシブルの 50 Ω です。Times Microwave の整理表では、M17/28-RG58 の誘電体は PE（ポリエチレン）、速度係数 66%、静電容量 30.8 pF/ft、インピーダンス 50 ±2 Ω、外径 0.195 インチ（4.95 mm）です。外部導体はすずめっき銅の編組、外被は PVC です。速度係数 66% は、充実のポリエチレンに対応する値で、発泡ではありません。掃引の範囲として書かれているのは 0.05–1 GHz です。

1 GHz の減衰は、同じ表で typical 15.3 dB/100 ft、M17 の最大 28.0 dB/100 ft です。メートルに直すと、およそ 0.50 dB/m と 0.92 dB/m です。Alpha の RG-58C/U（MIL-C-17/28 を参照するカタログ）も、1 GHz の最大を 28 dB/100 ft、誘電体を充実ポリエチレン、インピーダンスを 50 ±2 Ω としています。

用途は、この周波数範囲の汎用のフレキシブルです。1 GHz の損失が LMR-400 の 900 MHz より明らかに大きいので、長い給電線の低損失ケーブルとしては読みません。Amphenol の N 型カタログは、N 型が終端するケーブルの例に RG-58 を挙げています。

## RG-316

細いフレキシブルの 50 Ω です。整理表の M17/113-RG316 は、誘電体 PTFE、速度係数 69.5%、インピーダンス 50 ±2 Ω、外径 0.098 インチです。外部導体は銀めっき銅の編組、外被は FEP です。温度の行は −55 °C から +200 °C です。掃引の範囲として書かれているのは 0.05–3 GHz です。

1 GHz の減衰は、typical 26.1 dB/100 ft、最大 38.0 dB/100 ft です。およそ 0.86 dB/m と 1.25 dB/m です。Harbour Industries の MIL-DTL-17 整理も、1 GHz の最大を 38.0 dB/100 ft としています。Belden の 84316（M17/113-RG316 を参照する商用、非 QPL）は、誘電体 PTFE、公称インピーダンス 50 Ω、1 GHz の公称減衰 29.0 dB/100 ft です。typical と最大のあいだにあります。

用途は、細さと高温が要る機器内の引き回しです。太さの近いセミリジッドより、編組なので取り回しはしやすい側です。損失は、このページの呼びの中では大きい側です。

## RG-142

RG-58 と同じ外径 0.195 インチの 50 Ω で、誘電体が PTFE です。整理表の M17/60-RG142 は、速度係数 69.5%、インピーダンス 50 ±2 Ω、外部導体は銀めっき銅の編組が二重、外被は FEP です。温度の行は −55 °C から +200 °C です。掃引の範囲として書かれているのは 0.05–8 GHz です。表の注記は、50 Ω の低損失・高温用です。

1 GHz の typical は 12.8 dB/100 ft（およそ 0.42 dB/m）です。最大は、同じ表では 19.0 dB/100 ft です。Harbour Industries の整理は、1 GHz を typical 13.7、最大 15.3 dB/100 ft としています。typical はおよそ 0.4 dB/m で揃います。最大は、資料で 15.3 と 19.0 に分かれます。このページは、最大を一つの保証値にしません。

RG-58 と比べると、太さは同じで、誘電体と編組と温度の行が違います。損失の typical は RG-58 より小さく、掃引の上限の行は高くなっています。

## RG-402 と RG-405（セミリジッド）

外部導体が金属管の、セミリジッドです。手で繰り返し曲げる前提のものではありません。形そのものが仕様になる、という見方は [用語集]({{ '/glossary/' | relative_url }}#semi-rigid) と [現場の見方]({{ '/learn/field/' | relative_url }}) にあります。

整理表の M17/130-RG402 は、外径 0.141 インチ（3.58 mm）、誘電体 PTFE、速度係数 69.5%、インピーダンス 50 ±1 Ω、外部導体は銅管、外被なしです。掃引の範囲として書かれているのは 0.5–20 GHz です。1 GHz の typical は 11.2 dB/100 ft（およそ 0.37 dB/m）です。同じ行の最大は 12.0 dB/100 ft です。

M17/133-RG405 は、外径 0.0865 インチ（2.20 mm）、誘電体 PTFE、速度係数 69.5%、インピーダンス 50 ±1.5 Ω、外部導体は銅管です。掃引の範囲は、同じ表で 0.5–20 GHz です。1 GHz の typical は 19.2 dB/100 ft（およそ 0.63 dB/m）、最大は 22.0 dB/100 ft です。構造は 402 と同じ族で、細い分だけ損失は大きい側です。

用途は、機器の中で形を決めて置く高周波の配線です。管の外部導体なので、編組のフレキシブルより遮蔽は安定しやすい、と構造から読みます。遮蔽のデシベルを、このページでは製品の保証として書きません。

## LMR-400

Times Microwave Systems の、Flexible Low Loss Communications Coax です。データシートは、インピーダンス 50 Ω、誘電体は発泡ポリエチレン（Foam PE）、誘電率 1.38、速度係数 84%、外被を含めた外径 0.405 インチ（10.29 mm）としています。基本の LMR-400 の外被は、屋外用の黒の PE です。同じ系列に、屋外の防水や、屋内のライザー向けの外被違いがあります。

減衰の表に 1 GHz の行はありません。掲載されている近い点は、900 MHz で 3.9 dB/100 ft（12.8 dB/100 m、0.128 dB/m）、1.5 GHz で 5.1 dB/100 ft（16.8 dB/100 m）です。条件は、VSWR 1.0、周囲 +25 °C です。1 GHz は、この二つの掲載値のあいだの、900 MHz に近い側です。このページは、表にない 1 GHz を一つの掲載値としては書きません。

データシートが用途として挙げているのは、無線通信のジャンパ、短いアンテナ給電線、取り回しやすく損失の小さい高周波ケーブルです。RG-8 や 9913 の空気誘電体型からの置き換え、とも書いています。低損失ケーブル一般の総称ではありません。

## ハンドフォーマブル

セミリジッドに近い外径で、外部導体をすずで固めた編組にし、手で形をつけられるケーブルです。製品の総称であり、一つの規格番号ではありません。

一例は、HUBER+SUHNER の SUCOFORM 141 Cu です。データシートは、セミリジッドの代わりに手で成形できるマイクロ波ケーブル、と書いています。インピーダンスは 50 ±2 Ω、誘電体は PTFE、外径 3.58 mm（RG-402 の 0.141 インチと同じ呼び寸法）、外部導体はすずで満たした銅編組です。使用周波数の上限は 33 GHz、速度係数は 71% です。静的な最小曲げ半径は 8 mm、繰り返しは 40 mm で、繰り返しの回数は最大 50 回、と書かれています。セミリジッドを一度形にして終わり、とは、曲げの回数が違います。遮蔽は、0.1–18 GHz で 100 dB より大きい、と同シートにあります。

減衰の表の最初の点は 1.7 GHz で 0.53 dB/m です。係数は a = 0.355、b = 0.04 で、減衰（dB/m）= a√f + bf（f は GHz）です。1.7 GHz に入れると 0.53 と一致します。同じ式で 1 GHz を計算すると 0.40 dB/m（小数第 2 位で四捨五入）です。0.40 は表の行ではなく、係数からの計算です。RG-402 の 1 GHz typical（約 0.37 dB/m）に近い、という比較に使います。ほかのハンドフォーマブルが同じ損失、とは読みません。

## 低損失と、位相が動きにくいケーブル

低損失と位相安定は、別の指定です。低損失は、先へ届くまでの減衰が小さいことです。LMR-400 は、その例です。位相安定は、曲げや温度で電気的な長さが動きにくいことです。計測器のポートケーブルでは、こちらの方が合否になることがあります。

試験用の一例は、W. L. Gore の PHASEFLEX です。データシートは、曲げに対する損失と位相の安定をうたい、実験室、生産、フィールドの試験、とくにベクトルネットワークアナライザでの測定を用途に挙げています。上限はタイプにより、110 GHz までのものがあります。18 GHz までのタイプの表では、公称インピーダンス 50 Ω、公称の誘電率 1.4、公称の速度係数 85% です。一部のタイプは、曲げに対する位相と振幅の安定が保証項目です。同じ表には、典型の位相安定 ±2.0 度、振幅 ±0.05 dB 未満、と書かれた行があります。挿入損失の欄はアッセンブリの値なので、このページの dB/m の比較には使いません。

HUBER+SUHNER の SUCOFLEX 526V の資料は、従来の VNA 用ケーブルでは PTFE の phase knee が +19 °C 付近に出る、と書いています。位相が温度で段をつけるのは、充実 PTFE の性質として知られている、という説明です。位相安定をうたうケーブルの誘電体を、このページでは一つの材料名に固定しません。

低損失の給電線と、位相が落ちにくい試験ケーブルは、外径も誘電体も、図面の要求も違います。呼びを混ぜて代用しません。損失の dB を長さと周波数で読む手順は [同軸ケーブルの損失]({{ '/learn/cable-loss/' | relative_url }}) です。
