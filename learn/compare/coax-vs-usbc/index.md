# 同軸と USB-C

電話やパソコンの USB-C と、計測や無線の同軸は、どちらも「ケーブル」と呼ばれます。速い方が勝ち、ではありません。運んでいるものと、中の形が違います。このページは、その仕事の違いを、小学校の高学年から大人まで読めるように並べます。

数値は目安です。USB の世代や、同軸の系列で変わります。一つの数字を、すべての製品の保証だと思わないでください。

## どっちもケーブル、でも仕事が違う {#jobs}

USB-C のよくある仕事は、機器と機器のあいだで、データと電力をまとめて渡すことです。充電をしながら画面の情報を送る、といった頼み方を、一つのプラグに寄せています。

同軸ケーブルアッセンブリの仕事は、高周波の信号を、決まったインピーダンスの一本の道で運ぶことです。両端は高周波コネクタで、長さや曲げは図面で指定されます。計測器とアンテナのあいだ、試験機と基板のあいだ、といった「信号の通り道そのもの」が製品です。

どちらかが古くて、どちらかが新しい、という並びではありません。頼みが違うので、両方が残ります。

## 運んでいるもの：電波とデータ {#cargo}

同軸が運ぶのは、連続した高周波の波であることが多いです。強さ、周波数、位相が、そのまま意味になります。計測では、波がどれだけ反射して戻ったか、どれだけ弱くなったかを見ます。

USB-C が運ぶデータの多くは、0 と 1 の列です。ただし、0 と 1 の切り替わりは急なので、その縁には高い周波数の成分が含まれます。デジタルだから高周波と無関係、ではありません。速いモードほど、線の中では高い周波数の話が顔を出します。

もう一つ。USB-C は、機器を動かすための電力を同じプラグで運ぶことがあります。同軸でいう電力は、電波として送る電力の話で、スマホを充電する話とは別です。

## 得意なこと、苦手なこと {#fit}

同軸が得意なのは、一つの高周波の道を、反射と損失と位相まで含めて管理することです。計測器のポートや、ミリ波に近い試験では、系列と長さを指定したアッセンブリが残ります。苦手なのは、「充電もデータも映像も、上下を気にせず一つのプラグで」という頼みです。その頼みは USB-C の仕事です。

USB-C が得意なのは、たくさんの機器を、同じ形のプラグでつなぐことです。データと電力を一緒に扱えます。苦手なのは、50 Ω の高周波ポートの代わりを、形が違うからと務めることです。位相をピコ秒で揃えたり、110 GHz 級の界面に嵌合したりは、同軸の図面の仕事です。

## よくある誤解 {#myths}

- 「USB-C の方が速いから、同軸はもう要らない。」速さと、高周波を一本の道で運ぶことは、別の採点です。試験や無線では、同軸のアッセンブリが残ります。
- 「プラグの形が同じなら、性能も同じ。」USB-C は見た目が似ていても、中の線の数や、対応する速度が違います。同軸も、SMA という名前だけでは、中のケーブルも長さも決まりません。
- 「デジタルは 0 と 1 だから、高周波とは無関係。」切り替わりが速いほど、高い周波数の成分が増えます。線の長さと断面は、デジタルでも効きます。
- 「テレビの裏の同軸と、計測器の同軸は同じ。」テレビの受信用は 75 Ω であることが多いです。このサイトが主に扱う計測や無線は 50 Ω であることが多いです。数字が違うものを、形が合うからと混ぜると、境目で反射が戻ります。

## 速いデジタルも、高周波の話につながる {#bridge}

0 が 1 に変わる縁は、なだらかな波をたくさん重ねた形をしています。切り替わりを急にするほど、高い周波数の波が混ざります。だから速い USB のケーブルでも、対の線の間隔、盾、長さが成績に効きます。

同軸で先に習う「反射する」「インピーダンスが乱れると戻ってくる」は、速いデジタルの線でも同じ仲間の話です。入口は [入門]({{ '/learn/beginner/' | relative_url }})、言葉は [用語集の差動伝送]({{ '/glossary/' | relative_url }}#differential) です。
