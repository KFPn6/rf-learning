# LMR-200・LMR-240・LMR-400の違いと選び方

LMR-200、LMR-240、LMR-400 は、Times Microwave Systems の低損失フレキシブル同軸として名前が出ます。三枚のデータシートは、題を Flexible Low Loss Communications Coax と書き、LMR の名の横に登録商標を示す ® を置いています。外被の太さ、同じ周波数の減衰、曲げ半径は、三つで揃いません。このページは、その読み分けと、選ぶときに見る順番です。

数字は、その三枚の公開データシートから取った学習用の概数です。個別の製品が保証する値ではありません。外被の材料が分かれる行は、構造表とは別です。資料が違う行を、平均して一つの仕様にはしません。

呼びを広く並べた一覧は [ケーブルの種類]({{ '/learn/cable-types/' | relative_url }}) です。そちらにある LMR-400 は、一覧の中の一行です。このページは、200、240、400 の見分けです。dB を長さへ掛ける手順は [同軸ケーブルの損失]({{ '/learn/cable-loss/' | relative_url }})、LMR-400 の係数を入れて概算する電卓は [電卓]({{ '/learn/calculator/#cable' | relative_url }}) です。細い RG 三本の読み分けは [RG-174・RG-316・RG-58]({{ '/learn/rg-174-316-58/' | relative_url }}) です。径と比誘電率の式は [特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) です。ケーブルの呼びだけで端の系列は決まりません。N 型と SMA の例は [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) です。

## 外径

構造表の外被は、LMR-200 が 0.195 インチ（4.95 mm）、LMR-240 が 0.240 インチ（6.10 mm）、LMR-400 が 0.405 インチ（10.29 mm）です。欄は Jacket (see table) で、外径の数字は一本につき一つです。部品表の先頭は、いずれも屋外用の黒の PE です。同じ表に、防水、ライザー、PVC の行があります。外径の列は、その部品表にはありません。外被の材料が違っても外径は同じ、とは書きません。

インチのまま割ると、0.405 / 0.195 = 2.076923、0.405 / 0.240 = 1.6875、0.240 / 0.195 = 1.230769 です。小数第 2 位へ四捨五入すると、2.08 倍、1.69 倍、1.23 倍です。印刷されたミリメートルで割ると、10.29 / 4.95 = 2.078788、10.29 / 6.10 = 1.686885、6.10 / 4.95 = 1.232323 です。小数第 2 位は、インチの比と同じ 2.08、1.69、1.23 です。LMR-400 の外被は、この表の LMR-200 の 2.08 倍、LMR-240 の 1.69 倍です。LMR-240 は LMR-200 の 1.23 倍です。

中心導体の外径は、別の行です。LMR-200 は Solid BC の 0.044 インチ（1.12 mm）、LMR-240 は Solid BC の 0.056 インチ（1.42 mm）、LMR-400 は Solid BCCAI の 0.108 インチ（2.74 mm）です。構造表は、BC と BCCAI を金属名へほどいていません。このページでも、その略号を一つの金属名にはしません。

誘電体の外径は、発泡 PE で、LMR-200 が 0.116 インチ（2.95 mm）、LMR-240 が 0.150 インチ（3.81 mm）、LMR-400 が 0.285 インチ（7.24 mm）です。アルミテープの外径は 0.121 インチ（3.07 mm）、0.155 インチ（3.94 mm）、0.291 インチ（7.39 mm）です。編組の外径は 0.144 インチ（3.66 mm）、0.178 インチ（4.52 mm）、0.320 インチ（8.13 mm）です。外被の 4.95 mm を、編組の 3.66 mm には使いません。

## 構造

三枚の層の名前は、内側から、中心導体、発泡ポリエチレン（Foam PE）、アルミテープ（Aluminum Tape）、すずめっき銅の編組（Tinned Copper）、外被です。外部導体の欄がアルミテープで、その外側の Overall Braid が編組です。編組だけの一層、とも、金属管、とも書いていません。

シールディング効果は、三枚とも >90 dB です。電気仕様のその欄に、周波数も長さもありません。>90 dB を、三本の順位には使いません。印刷が同じだからです。dB の向きと、周波数の付いた遮蔽の読み方は [同軸ケーブルのシールド]({{ '/learn/shielding/' | relative_url }}) です。

## 減衰

比べるときは、同じ条件の、同じ周波数の行だけを使います。三枚の典型減衰の条件は、VSWR = 1.0、周囲 +25 °C です。900 MHz は、9.9、7.6、3.9 dB/100 ft です。1500 MHz は、12.9、9.9、5.1 dB/100 ft です。1 GHz の行は、三枚ともありません。

900 MHz の dB/100 ft だけで割ると、9.9 / 3.9 = 2.538462、7.6 / 3.9 = 1.948718、9.9 / 7.6 = 1.302632 です。小数第 2 位では、2.54 倍、1.95 倍、1.30 倍です。1500 MHz では、12.9 / 5.1 = 2.529412、9.9 / 5.1 = 1.941176、12.9 / 9.9 = 1.303030 です。小数第 2 位では、2.53 倍、1.94 倍、1.30 倍です。順序はどちらの行でも、LMR-400 が小さい側、次が LMR-240、LMR-200 が大きい側です。2.54 と 2.53 を、一つの比にはしません。

単位の換算は、1 ft = 0.3048 m なので 100 ft = 30.48 m です。dB/m は dB/100 ft を 30.48 で割り、dB/100 m は dB/100 ft に 100 / 30.48 を掛けます。900 MHz では、9.9 / 30.48 = 0.324803、7.6 / 30.48 = 0.249344、3.9 / 30.48 = 0.127953 です。小数第 3 位へ四捨五入すると、0.325、0.249、0.128 dB/m です。100 m 側は、9.9 ×（100 / 30.48）= 32.480、7.6 ×（100 / 30.48）= 24.934、3.9 ×（100 / 30.48）= 12.795 です。小数第 1 位では 32.5、24.9、12.8 です。シートが印刷している 32.6、24.8、12.8 と、小数第 1 位で揃うのは LMR-400 だけです。LMR-200 と LMR-240 は 0.1 ずれます。比を取るときは、印刷された dB/100 ft のままにします。0.128 dB/m は、[同軸ケーブルの損失]({{ '/learn/cable-loss/' | relative_url }}) が LMR-400 の 900 MHz に置いている換算です。ほかの二本の 900 MHz ではありません。

長さの例は、印刷された dB/100 m を使います。900 MHz、10 m では、32.6 ×（10 / 100）= 3.26 dB、24.8 ×（10 / 100）= 2.48 dB、12.8 ×（10 / 100）= 1.28 dB です。残る電力の比は 10^(−L/10) です。10^(−3.26/10) = 0.472063、10^(−2.48/10) = 0.564937、10^(−1.28/10) = 0.744732 です。比は小数第 4 位、百分率は小数第 2 位です。手順の置き場所は [同軸ケーブルの損失]({{ '/learn/cable-loss/' | relative_url }}) です。

| ケーブル | 900 MHz の印刷 | 10 m の減衰 | 残る電力の比 | 百分率 |
| --- | --- | --- | --- | --- |
| LMR-400 | 12.8 dB/100 m | 1.28 dB | 0.7447 | 74.47% |
| LMR-240 | 24.8 dB/100 m | 2.48 dB | 0.5649 | 56.49% |
| LMR-200 | 32.6 dB/100 m | 3.26 dB | 0.4721 | 47.21% |

</div>

この表は、典型減衰、VSWR = 1.0、周囲 +25 °C、整合を仮定したケーブル単体です。両端のコネクタは入っていません。10 m では、残る電力が 74.47%、56.49%、47.21% です。

任意の周波数の式は、k1×√(F_MHz) + k2×F_MHz で、結果は dB/100 ft です。LMR-200 は k1 = 0.320900、k2 = 0.000330 です。LMR-240 は k1 = 0.242080、k2 = 0.000330 です。LMR-400 は k1 = 0.122290、k2 = 0.000260 です。900 MHz では √900 = 30 です。LMR-200 は 0.320900×30 + 0.000330×900 = 9.627 + 0.297 = 9.924 です。LMR-240 は 0.242080×30 + 0.000330×900 = 7.2624 + 0.297 = 7.5594 です。LMR-400 は 0.122290×30 + 0.000260×900 = 3.6687 + 0.234 = 3.9027 です。小数第 1 位では 9.9、7.6、3.9 で、表と揃います。1500 MHz に同じ式を入れると、12.923404、9.870718、5.126271 です。小数第 1 位は 12.9、9.9、5.1 で、こちらも表と揃います。揃うのは、表にある行の確認です。表に無い 1 GHz を、この式の結果としてこのページには書きません。LMR-400 の係数を長さへ掛ける電卓は [電卓]({{ '/learn/calculator/#cable' | relative_url }}) です。LMR-200 と LMR-240 は、そのプリセットには入っていません。

中心導体の直流抵抗は、5.36、3.2、1.39 Ω/1000 ft です。5.36 / 1.39 = 3.856115、3.2 / 1.39 = 2.302158、5.36 / 3.2 = 1.675 です。小数第 2 位では、3.86 倍、2.30 倍、1.68 倍です。900 MHz の減衰の比は 2.54、1.95、1.30 です。直流の比を、900 MHz の減衰の比には使いません。

平均電力は、減衰の表の別の行です。900 MHz は 0.18、0.26、0.58 kW です。条件は VSWR = 1.0、周囲 +40 °C、中心導体 100 °C、海面、乾燥空気、大気圧、日射なし、です。減衰の周囲 +25 °C とは温度が違います。ピーク電力の欄は 2.5、5.6、16 kW で、周波数は書いてありません。0.18 kW と 2.5 kW を、一つの電力にはしません。

## 曲げ半径

施工時と反復は、別の行です。施工時は 0.5 インチ（12.7 mm）、0.75 インチ（19.1 mm）、1.00 インチ（25.4 mm）です。反復は 2 インチ（50.8 mm）、2.5 インチ（63.5 mm）、4.0 インチ（101.6 mm）です。同じシートのインチで割ると、2 / 0.5 = 4、2.5 / 0.75 = 3.333333、4.0 / 1.00 = 4 です。小数第 2 位では、4 倍、3.33 倍、4 倍です。施工時の 12.7 mm を、繰り返し曲げる半径には使いません。

0.75 インチを 25.4 倍すると 19.05 mm です。シートが括弧に置いているのは 19.1 mm です。19.05 を、シートの 19.1 の代わりには置きません。

温度の行は、三枚で同じです。施工と動作は −40 °C から +85 °C、保管は −70 °C から +85 °C です。華氏は、施工と動作が −40 °F から +185 °F、保管が −94 °F から +185 °F です。保管の −70 °C を、動作の下限には読みません。温度では、この三本は分かれません。

## 速度係数

速度係数は、LMR-200 と LMR-240 が 83%、LMR-400 が 84% です。誘電率は 1.45、1.42、1.38 です。1 / √1.45 = 0.830455、1 / √1.42 = 0.839181、1 / √1.38 = 0.851257 です。百分率の小数第 1 位は 83.0、83.9、85.1 です。シートの 83、83、84 と整数で揃うのは、LMR-200 だけです。誘電率から速度係数を計算し直して、印刷された 83% や 84% を置き換えません。遅れ時間の欄は、1.22 ns/ft（4.02 ns/m）、1.21 ns/ft（3.97 ns/m）、1.20 ns/ft（3.92 ns/m）です。速度係数の別の書き方としては使いません。式の置き場所は [特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) です。

## RG-58 と、RG-8/9913

LMR-200 の外被 0.195 インチ（4.95 mm）は、同じ Times Microwave Systems の M17 整理表が M17/28-RG58 の外被として置く 0.195 インチ（4.95 mm）と、同じ数字です。整理表の RG-58 は、充実ポリエチレン、速度係数 66%、外部導体はすずめっき銅の編組です。LMR-200 は、発泡ポリエチレン、速度係数 83%、アルミテープとその外の編組です。外径の数字が同じでも、誘電体と速度係数と外部導体の書き方は違います。同じケーブルとしては読みません。

減衰も、周波数の行が違います。整理表の RG-58 は 1 GHz の typical を持ち、LMR-200 の減衰表に 1 GHz の行はありません。15 dB/100 ft 前後と、9.9 dB/100 ft の割り算はしません。読み方は [同軸ケーブルの損失]({{ '/learn/cable-loss/' | relative_url }}) が、LMR-400 の 900 MHz と RG-58 の 1 GHz についてすでに置いているものと同じです。RG-58 の行の詳細は [ケーブルの種類]({{ '/learn/cable-types/' | relative_url }}) と [RG-174・RG-316・RG-58]({{ '/learn/rg-174-316-58/' | relative_url }}) です。

RG-8 と 9913 の文は、LMR-400 のシートだけにあります。用途の先頭は、Drop-in replacement for RG-8/9913 Air-Dielectric type Cable、です。LMR-200 と LMR-240 の用途の欄には、この文はありません。LMR-400 の文を、200 と 240 へは広げません。このページは、RG-8 と 9913 の外径を、別の資料から足していません。

三枚が用途として並べているのは、無線通信のジャンパ、短いアンテナ給電線、取り回しやすく損失の小さい高周波ケーブルです。括弧の例示は、シートで少し違います。例示の中に LMR という語があります。製品名の LMR-200 と同じ綴りです。その例示を、ケーブルの呼びには読みません。例示の違いで、三本の選択はしません。

## 選び方

見る順番は、次です。

- 通る太さは、構造表の外被です。インチの比では、LMR-400 が LMR-200 の 2.08 倍、LMR-240 の 1.69 倍、LMR-240 が LMR-200 の 1.23 倍です。部品表の外被が PE 以外の行でも、外径は構造表の一つの数字しかありません。別の外径が要るときは、その行の資料を見ます。
- 曲げは、施工時と反復を分けます。反復は、施工時の 4 倍、3.33 倍、4 倍です。小さい方の半径を、繰り返しの半径には使いません。組としての曲げは [アッセンブリの構造と製作工程]({{ '/learn/assembly-basics/' | relative_url }}) です。
- 減衰は、同じ周波数の行です。900 MHz でも 1500 MHz でも、小さい側から LMR-400、LMR-240、LMR-200 です。比は、900 MHz で 2.54 と 1.95 と 1.30、1500 MHz で 2.53 と 1.94 と 1.30 です。1 GHz の行は無いので、このページは 1 GHz の掲載値を書きません。長さへの掛け算は [同軸ケーブルの損失]({{ '/learn/cable-loss/' | relative_url }})、LMR-400 の係数を入れた概算は [電卓]({{ '/learn/calculator/#cable' | relative_url }}) です。
- 中心の直流抵抗の比は、900 MHz の減衰の比より大きい側です。3.86 を 2.54 の代わりには使いません。
- シールディング効果の >90 dB は、三枚で同じ印刷です。遮蔽では、この三本は分かれません。周波数の付いた dB は [同軸ケーブルのシールド]({{ '/learn/shielding/' | relative_url }}) です。
- 速度係数は 83%、83%、84% です。誘電率の逆平方根で計算し直した 83.9% と 85.1% は、シートの 83% と 84% ではありません。
- 温度の行も、三枚で同じです。動作の −40 °C から +85 °C で、この三本は分かれません。保管の −70 °C は、動作の下限ではありません。
- 外径が RG-58 の整理表と揃うのは、LMR-200 の 0.195 インチです。速度係数は 83% と 66% で、誘電体は発泡と充実です。RG-8/9913 の空気誘電体型からの置き換え、と書いているのは LMR-400 だけです。
- むき工具は、ケーブルの呼びで分かれます。LMR-400 の工具を、LMR-200 の寸法には使いません。名前の例は [数値早見]({{ '/learn/quick-reference/' | relative_url }}) です。減衰の表が 8000 MHz まであることを、端のコネクタの使用周波数の上限には読みません。上限の読み分けは [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。
