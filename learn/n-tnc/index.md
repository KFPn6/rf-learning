# N型とTNCの違いと使い分け

N 型と TNC は、どちらもねじ結合の同軸コネクタです。掛かる山は違います。IEC 61169-16:2006 の題は、外導体内径 7 mm（0.276 in）、ねじ結合、特性インピーダンス 50 Ω（75 Ω）、type N です。IEC 61169-17:2022 の題は、外導体内径 6.5 mm（0.256 in）、ねじ結合、特性インピーダンス 50 Ω、type TNC です。Rosenberger の RPC-N は、結合ねじを 5/8-24 UNEF と書きます。TNC の呼びは、IEC 61169-26 の図と、Rosenberger の RPC-TNC が 7/16-28 UNEF と書きます。5/8-24 のナットは、7/16-28 には進みません。系列をまたぐときは、変換アダプタです。

Rosenberger の市販 TNC の案内は、BNC の特性と界面寸法に基づく、と書きます。続けて、ねじのロックにより、BNC に比べて高い環境負荷で使える、とも書きます。基づく、と、高い環境負荷、は、別の文です。N 型の題の 7 mm へ、その文は届いていません。同じ案内の注は、展開を Threaded Neill Concelman と Thread Navy Connector の二つ書きます。このページは、どちらの展開も採りません。経緯と発明者は、断定しません。

ここにある数字は、公開の規格のプレビューと、メーカーの技術資料、計測器メーカーのアプリケーションノートから取った学習用の目安です。個別の製品が保証する値ではありません。同じ名前でも、資料が複数の周波数と、複数の電力と、複数のトルクを置きます。平均して一つの上限にはしません。

系列の早見は [コネクタの種類]({{ '/learn/connector-types/' | relative_url }}) です。同じねじ同士の SMA との呼びの違いは [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) です。ねじの N 型と、バヨネットの BNC は [N型とBNC]({{ '/learn/n-bnc/' | relative_url }}) です。同じ 6.5 mm の呼びで、バヨネットとねじを分ける組は [BNCとTNC]({{ '/learn/bnc-tnc/' | relative_url }}) です。どちらもねじである SMA と TNC は [SMAとTNC]({{ '/learn/sma-tnc/' | relative_url }}) です。このページは、どちらもねじである N 型と TNC のあいだです。N 型の 50 Ω と 75 Ω の見分けと、誤嵌合の注意は [N型の50Ωと75Ω]({{ '/learn/n-50-75/' | relative_url }}) です。このページは、N 型に両方があることと、その導線にとどめます。TNC の 50 Ω と 75 Ω は、このページで確認できた範囲だけを書きます。BNC や N 型のピン径の見分けは写しません。上限を平均しない読み方は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。帯域名との対応は [規格・周波数]({{ '/spectrum/' | relative_url }}) です。N 型も TNC も、コネクタの呼びです。帯域名ではありません。

## ねじの呼びと、外導体の径

IEC 61169-16:2006 の適用範囲は、ピンとソケットの高周波同軸コネクタで、結合はねじ、用途の文は低から中の電力です。通称は type N、と書きます。50 Ω には三つの grade があり、互いに嵌合しうる、と続きます。Webstore の公開案内は、題と、低から中の電力と、50 Ω の三つの版が互いに嵌合できること、までです。GHz の文と、5/8-24 の文字は、その案内にはありません。周波数は、開いたプレビューの適用範囲で置きます。

ピン中心の表で、a は 7.00 nom、インチ欄は 0.2756 nom、注は直径です。c は 5/8-24 UNEF-2B で、注は ISO 263 のねじです。同じプレビューの 4.1.1 は、インチ寸法が原寸で、ミリメートルは必ずしも厳密ではない、と書きます。題の括弧は 0.276 in です。0.276 × 25.4 = 7.0104、0.2756 × 25.4 = 7.00024 です。この計算を、表の公差にはしません。ソケット中心の表は、開いた 11 ページの範囲にはありません。ソケット側の 5/8-24 UNEF-2A を、このプレビューの文字としては置いていません。

ねじの両側は、Rosenberger の RPC-N 50 Ω の技術資料で置きます。プラグの F は 5/8-24UNEF-2B、ジャックの F は 5/8-24UNEF-2A です。2B は内ねじ、2A は外ねじの等級です。B は両列とも 6.99–7.01 mm です。題の 7 mm、表の 7.00 nom、B の 6.99–7.01 を、一つの径にはしません。プラグの G は hex 19 です。ジャックの G は、その表にありません。5/8 インチは 0.625 インチで、0.625 × 25.4 = 15.875 mm です。これはねじの呼び径の換算であり、結合ナットの二面幅ではありません。hex 19 とも、別です。

IEC 61169-17:2022 の適用範囲は、ねじ結合、特性インピーダンス 50 Ω の series TNC です。動作周波数は 11 GHz まで、と書きます。外導体内径の呼びは 6.5 mm（0.256 in）です。注は、ミリメートルが原寸、と書きます。N 型のプレビューがインチを原寸とする文と、この注は、別の規格の文です。Webstore の公開案内は、題と、詳細仕様の規則までです。11 GHz の文は、その案内の要旨にはありません。開いたプレビューの表に、7/16-28 の文字はありません。図の注に、封止のリング、とあります。結合ナットを前に出した位置、という注もあります。

呼びは、別の資料で置きます。IEC 61169-26:2013 のピン中心の図は 7/16-28UNEF-2B、ソケット中心の図は 7/16-28UNEF-2A です。Rosenberger の RPC-TNC も、プラグの F が 7/16-28 UNEF-2B、ジャックの F が 7/16-28 UNEF-2A です。ピン中心の側に結合ナットの内ねじがある、という並びは、RPC-N の技術資料と同じ側です。山の数字が違います。

7/16 インチは 0.4375 インチです。0.4375 × 25.4 = 11.1125 mm です。これはねじの呼び径の換算であり、結合ナットの二面幅ではありません。外導体内径の題の 6.5 mm でもありません。RPC-TNC の技術資料で、このページが読んだ寸法の行に、レンチ開口の数字はありません。11.1125 を、開口のミリメートルには読みません。15.875 を、TNC の開口にも読みません。

Amphenol の N の特徴は、5/8-24 のねじ結合とします。同じ社の TNC の現行ページは、結合をねじ、界面を MIL-STD-348 とします。N の仕様表の界面も MIL-STD-348 です。同じ規格名であることが、同じ嵌合面だという意味にはなりません。MIL-STD-348 の図そのものは、このページでは読んでいません。TNC の現行ページに、7/16-28 という文字は、このページでは見つかっていません。無い呼びを、そのページの文としては作りません。

SMA は 1/4-36 です。F 型は、別のねじの 75 Ω です。5/8-24 も 7/16-28 も、その相手には進みません。読み分けは [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) と [SMAとTNC]({{ '/learn/sma-tnc/' | relative_url }}) と [F型コネクタ]({{ '/learn/f-type/' | relative_url }}) です。バヨネットのスタッドは、どちらのねじでもありません。[N型とBNC]({{ '/learn/n-bnc/' | relative_url }}) と [BNCとTNC]({{ '/learn/bnc-tnc/' | relative_url }}) です。

## 周波数の目安

周波数は、学習用の目安です。製品が保証する上限ではありません。

N 側で、このページが並べる行は次です。IEC 61169-16:2006 の適用範囲は、grade 2 をおよそ 12 GHz、grade 1 の一部を 18 GHz まで、grade 0 を 18 GHz まで、とします。Webstore の公開案内に、この GHz の文はありません。Amphenol の標準は DC–11 GHz、拡張は DC–18 GHz です。Rohde & Schwarz の 1MA99 は、タイプ N（50 Ω）の最大周波数を、通常型 11 GHz、精密型 18 GHz、と書きます。同じノートの図は、市販のコネクタの動作周波数の例として、Type N を 11 GHz、Precision N を 18 GHz に置きます。英語版（2015 年 4 月、1MA99_2e）と、日本語版（2012-12-12、Version 1.0）で、この 11 と 18 の並びは同じです。二つの版の全文が同一だとは、このページでは確認していません。Rosenberger の RPC-N の製品案内は、50 Ω を 18 GHz まで、75 Ω を 4 GHz まで、とします。技術資料の 50 Ω の行は DC to 18 GHz です。4、11、12、18 を平均しません。

TNC 側の行は次です。IEC 61169-17:2022 の適用範囲は、11 GHz までです。Amphenol の現行ページは、DC–11 GHz、拡張設計は DC–18 GHz です。特徴の文は、11 GHz まで、ケーブルに依存する、とも書きます。仕様表の VSWR は、DC–11 GHz で最大 1.3 です。この電気の表のインピーダンスは 50 Ω です。FAQ は、標準を 11 GHz まで、拡張設計を 18 GHz まで、と書きます。11 と 18 を平均しません。特徴の「ケーブルに依存」を、表の拡張 18 GHz の注へは写しません。

Rosenberger の市販 TNC は、50 Ω が最大 DC–10 GHz、最適 DC–4 GHz、75 Ω が最大 DC–4 GHz、最適 DC–1.5 GHz です。導入の行は、50 Ω を最大 10 GHz、75 Ω を最大 4 GHz で依頼に応じて、と書きます。依頼に応じて、を、75 Ω の行が無い、とは読みません。10 と 11、4 と 1.5 を、一つの TNC の上限にはしません。

18 GHz は、さらに別の行です。IEC 61169-26:2013 の適用範囲は、TNCA、50 Ω、ねじ結合、動作周波数の限度は 18 GHz まで、です。11 GHz を超える用途に勧める、とも書きます。Webstore の公開案内の要旨には、18 GHz まで、はあります。11 GHz を超える、という文は、その要旨にはありません。Rosenberger の RPC-TNC は、界面を IEC 61169-26、周波数を DC–18 GHz とします。Amphenol の拡張設計の 18 GHz を、IEC 61169-17 の 11 GHz の更新には読みません。RPC-TNC の 18 GHz を、市販 TNC の最適 4 GHz の更新にも読みません。N 型の 18 GHz を、TNC の 18 GHz の同じ行にも読みません。系列が違います。

15 GHz は、図の例です。同じ 1MA99 の図は、TNC を 15 GHz、Type N を 11 GHz、Precision N を 18 GHz に置きます。英語版の図番号は Fig. 3-1、日本語版は図 1 です。どちらも、市販のコネクタの動作周波数の例、と前の文が書きます。TNC だけの節は、目次にも本文にもありません。図の 15 を、節で説明された上限には読みません。英語版と日本語版で、図の TNC が 15、Type N が 11、という並びは同じです。二つの版の全文が同一だとは、このページでは確認していません。15 を、IEC 61169-17 の 11 の更新には読みません。15 を、IEC 61169-26 の 18 の更新にも読みません。図の 11 を、Amphenol の拡張 18 の更新にも読みません。

6 GHz は、また別の案内です。開いた Amphenol の TNC のページには、低損失ケーブル向けに作り直した SMA、TNC、N 型の案内が並び、SMA は 12.4 GHz まで、TNC と N 型は 6 GHz まで、と書きます。これは、仕様表の DC–11 GHz と拡張の DC–18 GHz の行ではありません。6 を、11 や 18 の更新には読みません。N 型のシリーズページの仕様表に、この 6 の行は、このページでは見つかっていません。無い行を、TNC のページの案内で埋めません。

図の前の文は、より小さい同軸の形状ほど、使える上限が高くなる例がある、と書きます。TNC の題の 6.5 mm は、N 型の題の 7 mm より小さい側です。同じ図の棒は、TNC が 15、Type N が 11、Precision N が 18 です。小さい側の棒が、この図では N 型の精密の 18 より高い側ではありません。径が小さい方が、その製品の定格まで自動で伸びる、とはその文は書いていません。同じノートは、具体の型の性能は、必ずメーカーに確認する、と書きます。カットオフの計算へ寸法を入れる読み方は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。このページは、その計算を N 型と TNC の保証値にはしていません。

## 電力の目安

電力も、資料の文のまま置きます。ワットを平均して、一つの上限にはしません。

IEC 61169-16 の適用範囲は、低から中の電力、と書きます。ワットの数字は、その文にはありません。高電力の系列だ、とは書いていません。IEC 61169-17 の開いた適用範囲に、電力という語のワットの行は、このページでは見つかっていません。IEC 61169-26 の開いた適用範囲にも、ワットの数字はありません。無い行を、低から中、で埋めません。低から中、を、TNC の電力の文には読みません。

Amphenol の仕様表は、N を 300 W @ 10 GHz @ 25 °C、TNC を 316 W @ 1 GHz @ 25 °C とします。注は、これらの特性は典型値で、すべてのコネクタには当てはまらない、です。300 と 316 を、一つの耐電力の順位にはしません。周波数の条件が違います。316 を 10 GHz へ、300 を 1 GHz へは写しません。300 を、すべての N 型の定格にはしません。316 を、すべての TNC の定格にもしません。

Rosenberger の RPC-N の技術資料に、電力の行はありません。RPC-TNC の技術資料にも、電力の行はありません。無い行を、300 W や 316 W で埋めません。

電圧も、単位の書き方が分かれます。一つの比にはしません。Amphenol の N は連続 500 V rms、耐電圧 1500 V rms です。同じ社の TNC は 500 V peak、耐電圧 1500 V rms です。500 rms と 500 peak は、同じ文字ではありません。Rosenberger の RPC-N は、試験電圧 2500 V rms、動作電圧 1000 V rms、またはケーブルの制限、です。RPC-TNC は、試験電圧 1500 V rms、動作電圧 500 V rms、またはケーブルの制限、です。1500 が、N では Amphenol の耐電圧、TNC の精密資料では試験電圧、という並びです。一つの 1500 にはしません。

このサイトが中〜大電力の例に置く 7/16 は、別のねじと、別のトルクです。25–30 N·m を、N 型にも TNC にも使いません。外導体内径とトルクの読み分けは [7/16と4.3-10]({{ '/learn/7-16-43-10/' | relative_url }}) です。

## インピーダンス

N 型には、50 Ω と 75 Ω があります。このページは、そこまでです。

IEC 61169-16 の題は、50 Ω（75 Ω）です。Rosenberger の RPC-N の製品案内は、50 Ω と 75 Ω の両方を置きます。同じインピーダンス同士だけが嵌合する、と書きます。50 Ω は 18 GHz まで、75 Ω は 4 GHz までです。18 を、75 Ω の行へは写しません。Amphenol の現行の N の仕様表のインピーダンスは 50 Ω です。その表に、75 Ω の行は、このページでは見つかっていません。無い行を、題の括弧で埋めません。ピンの大小、ねじが共通でも嵌合してはいけないこと、資料で分かれる上限の読み分けは [N型の50Ωと75Ω]({{ '/learn/n-50-75/' | relative_url }}) です。

TNC には、50 Ω と 75 Ω を置く資料があります。IEC 61169-17 の題と、IEC 61169-26 の適用範囲は、どちらも 50 Ω です。開いたプレビューと、Webstore の要旨に、75 Ω の TNC を定める文は、このページでは見つかっていません。無い文を、規格が 75 Ω を禁じた、とも読みません。

Amphenol の現行ページは、特徴に 50 Ω と 75 Ω がある、と書きます。電気の表のインピーダンスは 50 Ω です。VSWR の 1.3 は、DC–11 GHz の行です。75 Ω の周波数を、この 1.3 の行へは写しません。同じページに、75 Ω だけの周波数の行は、このページでは見つかっていません。無い行を、50 Ω の 11 GHz や 18 GHz で埋めません。

Rosenberger の市販 TNC は、50 Ω と 75 Ω の両方を置きます。50 Ω の界面の案内も、75 Ω の界面の案内も、IEC 60169-17、MIL-PRF-39012、DIN EN 122200 です。75 Ω 専用の別番号を、その案内は挙げていません。同じ案内は、国際的に標準化された TNC の界面寸法では、完全な 75 Ω は実現できない、と書きます。周波数は、前の節の 10 GHz、4 GHz、1.5 GHz のままです。

RPC-TNC の製品案内は、標準の TNC、50 Ω と 75 Ω の両方と相互嵌合する、と書きます。RPC-TNC 自身のインピーダンスの欄は 50 Ω です。嵌合できることを、電気的に同じ系統だ、とは読みません。18 GHz の行を、75 Ω の市販系列の最適 1.5 GHz へは写しません。

50 Ω か 75 Ω かは、ねじが見えることだけでは決まりません。部品番号、刻印、データシートで分けます。N 型でピンの大小をどう読むかは、このページでは書きません。[N型の50Ωと75Ω]({{ '/learn/n-50-75/' | relative_url }}) です。BNC のピン径や誘電体の見え方も、写しません。[BNC の 50 Ω と 75 Ω]({{ '/learn/bnc-50-75/' | relative_url }}) です。境目の反射を欄へ入れるなら [電卓]({{ '/learn/calculator/#reflect' | relative_url }}) です。その計算を、5/8-24 と 7/16-28 の違いを表す数字には使いません。

## 大きさと、屋外と、着脱と、振動

大きさ、屋外、着脱、振動も、資料の文のまま置きます。一つの「N 型は屋外、TNC は室内」にはまとめません。

外導体内径の題は、N 型が 7 mm、TNC が 6.5 mm です。これは胴の外径ではありません。1MA99 は、タイプ N を、耐久性があり、耐候性があり、中サイズ、と書きます。これは、開発したときの要求の文です。すべての個体が、ある IP 等級だ、とは書いていません。7 mm と 6.5 mm の差を、中サイズの測定結果には読みません。TNC を、その中サイズの小さい側、と測った文は、開いた資料にはありません。

屋外の語も、資料で分かれます。Amphenol の N の概要は weatherproof と書きます。IP67 は、選択モデルの行です。例として、現場で取り付ける LMR-400 のプラグを挙げます。FAQ は、多くの設計が耐候または IP のシールを選べる、と書きます。すべての N 型が IP67 だ、とは書いていません。IEC の N の寸法注は、ガスケットが無いときの寸法だ、と書きます。シールが要るときは、選んだガスケットで相手の前面に圧力がかかるよう、寸法 f を決める、と続きます。

Amphenol の TNC は、IP67 のシールを選べる、と書きます。見出しも、IP67 の選択肢、と置きます。すべての TNC が IP67 だ、とは書いていません。IEC 61169-17 の図の注は、封止のリング、です。寸法 s の注は、電気と封止の性能を満たす、と書きます。この注を、Amphenol の IP67 の等級には読みません。Rosenberger の RPC-TNC の材料欄に、ガスケットの行があります。精密系列の材料の行であり、市販の TNC 全体の IP 等級ではありません。屋外で使う一本は、その図面の IP と、ガスケットの有無を見ます。

着脱の速さも、一つの秒数にはしません。どちらもねじです。BNC の約四分の一回転を、どちらのナットへも使いません。Rosenberger の市販 TNC は、ねじのロックにより、確実で速く容易な接続ができ、BNC に比べて高い環境負荷で使える、と書きます。高い環境負荷の比較の相手は BNC です。速い、の秒数は、その文にはありません。N 型との時間の比較も、その文にはありません。1MA99 の取り扱いの節は、規定のトルクまで校正済みのトルクレンチで締める、と書きます。この手順を、N 型だけのものには読みません。開いた TNC のページに、四分の一回転で終わる、という文はありません。バヨネットとの読み分けは [N型とBNC]({{ '/learn/n-bnc/' | relative_url }}) と [BNCとTNC]({{ '/learn/bnc-tnc/' | relative_url }}) です。

振動も、順位にはしません。資料が「ねじだから振動に強い」と書く文と、振動試験の条件の文字は、別です。Amphenol の N の特徴は、振動のもとでも安定な接続、と書きます。環境の表は、振動を MIL-STD-202 Method 204 の Test Condition B とします。同じ社の TNC は、特徴の一つを、振動への抵抗のためのねじ結合、とします。環境の表も、同じ Method 204 の Test Condition B です。N の B と、TNC の B が同じ文字でも、耐振動が同じだ、という測定結果には読みません。Rosenberger の RPC-TNC は Condition D です。Amphenol の標準の B を、その D の代わりにも読みません。RPC-N の技術資料の振動は、IEC 61169-1 の細分箇条です。Method 204 の B や D と同じ文字ではありません。B と D の加速度を順位にしない読み方は [BNCとTNC]({{ '/learn/bnc-tnc/' | relative_url }}) です。このページは、Method 204 の加速度の本文を読んでいません。使う一本は、その図面の振動の行を見ます。

## 用途の置き場所

用途も、資料の文のまま置きます。一つの「N 型は通信、TNC はアンテナ」にはまとめません。置き場所の目安は、その文を読んだあとの案内です。規則ではありません。

Amphenol の N の見出しは、無線インフラ、産業、屋外向けの、丈夫で耐候性のある中型の接続、です。用途の列には、携帯電話の基地局、衛星通信、放送、計測、レーダ、屋外のアンテナがあります。1MA99 は、測定機器で使う同軸コネクタの選定と取り扱いの案内です。タイプ N の節は、その案内の中にあります。Rosenberger の RPC-N の用途は、50 Ω で 18 GHz まで、75 Ω で 4 GHz までの精密測定、セミリジッドとマイクロ波部品、航空宇宙向けの品種、です。屋外の基地局だけ、とは書いていません。

Amphenol の TNC は、無線インフラ、産業、試験と計測、屋外、アンテナ、と書きます。Rosenberger の市販 TNC は、航空宇宙、通信、移動体、と書きます。RPC-TNC の製品案内は、18 GHz までの精密測定、セミリジッドとマイクロ波部品、航空と宇宙向けの品種、と書きます。屋外という語が両方のページにあっても、すべての個体が屋外用だ、とはその文は書いていません。基地局という語が両方に出ても、結合の山は 5/8-24 と 7/16-28 のままです。計測という語が両方に出ても、同じです。

ケーブルの例も、系列を一つに決めません。Amphenol の N の概要は、RG-213、LMR-400、RG-55、RG-174 を例にします。TNC の案内は、RG-58、RG-142、RG-316 を例にします。開いた二つのページで、同じケーブル名が両方の例に並ぶ、という行は、このページでは見つかっていません。無い共通の例を、作りません。ケーブルの呼びだけで、端の系列は決まりません。

## トルク

推奨のレンチ設定として、一つの N·m にはしません。N 型の行を、TNC のナットへは使いません。逆も同じです。

Rosenberger の RPC-N は、推奨を 0.70–1.10 N·m、結合の試験トルクを 1.70 N·m とします。1.70 を、毎日のレンチ設定には読みません。Amphenol の標準 N は、Mating Torque, Min Working の欄が 8–12 inch-pounds で、同じ表に N·m はありません。インチポンドを、このページで換算して推奨値にはしません。1MA99 の表は、N-Type を 13.3 lb-inch、1.5 N·m、ナット開口 3/4 インチ、20 mm とします。注は、表の値はローデ・シュワルツが供給するコネクタ向けで、SMA は除く、と書きます。英語版と日本語版で、13.3 lb-inch、1.5 N·m、3/4 インチ、20 mm、という並びは同じです。部品番号は、二つの版で違います。このページは、部品番号を置きません。1.5 を、0.70–1.10 の更新には読みません。3/4 インチ × 25.4 = 19.05 mm です。この計算は、インチの開口の換算です。同じ行が 20 mm と書くことと、19.05 を、一つの開口にはしません。hex 19 を、その 20 mm の更新にも読みません。hex 19 を、N のジャックや、ほかのメーカーの全部へは写しません。

TNC で確認できた推奨は、二つです。Amphenol の現行ページは 4–6 inch-pounds（0.51–0.67 N·m）です。単位の併記は、そのページにあります。このページで換算し直した数字ではありません。Rosenberger の RPC-TNC は 0.46–0.69 N·m です。同じ技術資料の結合の試験トルクは 1.70 N·m です。1.70 の前後に、以上とも以下とも書かれていません。1.70 を、毎日のレンチ設定には読みません。0.51–0.67 と 0.46–0.69 を、一つの幅にはしません。N 型の 0.70–1.10 N·m を、このどちらの幅の更新にも読みません。1MA99 のトルクの表に、TNC の行は、このページでは見つかっていません。無い行を、N-Type の 1.5 N·m で埋めません。

開口の工具も、系列で代用しません。RPC-N のプラグは hex 19 です。RPC-TNC の技術資料の寸法の行に、レンチ開口の数字はありません。19 mm の開口を、TNC のナットの代わりにも使いません。掛けてから、試験トルクの 1.70 N·m が両方に書いてあるから代用する、という順にはしません。

技術資料の末尾は、個々の値は用途、設計、ケーブル、組立、作業によって異なりうる、と書きます。上の幅を、すべての個体の設定値には読みません。締付の残りの読み方は [コネクタの取り扱い]({{ '/learn/connector-care/' | relative_url }}) と [数値早見]({{ '/learn/quick-reference/' | relative_url }}) です。

## 見分けのポイント

見るのは、ねじの呼びと、ナットの大きさです。どちらも、回し続けるナットです。スタッドが約四分の一回転で掛かる相手は、このページの対ではありません。

指で回し始めて、山が噛み合わない相手は、その対ではありません。5/8-24 は 7/16-28 に進みません。金色に見えること、白い樹脂が見えること、全体が大きいことは、N 型と TNC を分けません。中心がピンか穴かだけでも、決まりません。資料上のプラグは、どちらの系列も、結合の側にピンを置く形があります。外導体内径の題は、7 mm と 6.5 mm で違います。目視の太さを、その呼びの測定にはしません。

ねじがあることだけでも、どちらかには決まりません。SMA は 1/4-36 です。N 型の資料が書く二面幅の一例は、RPC-N プラグの hex 19、または 1MA99 の 3/4 インチと 20 mm です。TNC の呼び径の換算 11.1125 mm を、その 19 mm のレンチが合う、とは読みません。19 mm のレンチを、TNC のナットの代わりにも使いません。

50 Ω か 75 Ω かも、このねじだけでは決まりません。N 型の見分けは [N型の50Ωと75Ω]({{ '/learn/n-50-75/' | relative_url }}) です。TNC で確認できた書き方は、上の節です。

同じ呼びのまま中心を入れ替えた資料は、標準の相手と対になりません。極性という考えは [SMA と RP-SMA]({{ '/learn/sma-rp-sma/' | relative_url }}) へ任せます。TNC 側の有無は、次の節の短い注意です。SMA のねじが 3.5 mm や 2.92 mm に合う話は、N 型の 5/8-24 にも、TNC の 7/16-28 にも写しません。[互換のページ]({{ '/learn/sma-35-292-compat/' | relative_url }}) です。

## 直接は嵌合しない

5/8-24 の山と、7/16-28 の山は、掛かり合う相手ではありません。外導体内径の題が 7 mm と 6.5 mm で違うことと、どちらもねじであることは、ロックする、という意味にはなりません。山が掛からないところから、力でねじを作りません。

系列をまたぐときは、変換アダプタです。1MA99 は、違う型を一つの系で使うときは、周波数範囲が最も低い型が、系の周波数範囲を決める、と書きます。アダプタ自身の行も、別に見ます。両側のうち高い方まで使える部品だ、とは、その文は書いていません。ケーブル側で届かないこともあります。読み方は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。

Amphenol の N の案内は、SMA、TNC、F 型などへの cross-series adapter を、製品の列に置きます。同じ社の TNC のページは、適合する TNC のアダプタがある、と書きます。N 型への型番は、その文にはありません。Rosenberger の RPC-N も、市販の TNC も、製品の列にアダプタを置きます。N 型から TNC への型番は、その列の文にはありません。無い型番を、このページでは作りません。

## 逆極性の短い注意

RP-TNC は、資料にあります。極性という考えの説明は [SMA と RP-SMA]({{ '/learn/sma-rp-sma/' | relative_url }}) へ任せます。このページは、有無と、誤嵌合への注意だけです。

Amphenol の RP-TNC のページは、逆極性の界面は標準の TNC と嵌合しない、と書きます。結合はねじのままです。逆極性のオスはメス型の接触子を持ち、その逆もそうである、とも書きます。ナットが回ることを、標準の TNC と対になった、とは読みません。周波数の表は、50 Ω、DC–11 GHz、拡張は DC–18 GHz です。この 11 と 18 を、標準の TNC のページの 11 と 18 の更新には読みません。別のページの行です。N 型の 5/8-24 へ、この界面が掛かる、とも書いていません。

Rosenberger の reverse の案内は、SMA、BNC、TNC の reverse を、規格化されていない版として置きます。TNC Reverse の行は、50 Ω、最大 DC–10 GHz、最適 DC–4 GHz、ねじ、中心を逆にする、嵌合 500 回以上、依頼に応じて、です。同じ案内の用途は、無線 LAN のルータだけ、と書きます。利益の行は、誤った接続は不可能、と書きます。この二つの文は、SMA と BNC の reverse と同じ案内にあります。すべての TNC に、この系列がある、とは読みません。10 GHz と 4 GHz を、市販の標準 TNC の 10 GHz と 4 GHz と、一つの行にはしません。標準と、reverse は、別の案内です。N 型の reverse を、その案内は置いていません。無い行を、TNC Reverse で埋めません。

## 選定するときに見ること

- 図面で、N 型か TNC か TNCA か、50 Ω か 75 Ω か、プラグかジャックか、標準か逆極性か、を見ます。大きいねじ、という一語では注文しません。N 型の 50 Ω と 75 Ω は [N型の50Ωと75Ω]({{ '/learn/n-50-75/' | relative_url }}) です。
- 周波数は、資料の行のまま置きます。N 型は、IEC のおよそ 12 GHz と 18 GHz、Amphenol の DC–11 GHz と DC–18 GHz、1MA99 の 11 GHz と 18 GHz、図の 11 GHz と 18 GHz、RPC-N の 18 GHz と 4 GHz です。TNC は、IEC 61169-17 の 11 GHz、Amphenol の 11 GHz と拡張の 18 GHz、Rosenberger の市販系列の 4 GHz と 10 GHz、75 Ω の 1.5 GHz と 4 GHz、図の例の 15 GHz、TNCA と RPC-TNC の 18 GHz です。低損失ケーブル向けの案内の 6 GHz は、仕様表の行ではありません。
- 電力は、IEC の低から中、を TNC の文にはしません。ワットが読めたのは、Amphenol の N の 300 W @ 10 GHz @ 25 °C と、TNC の 316 W @ 1 GHz @ 25 °C です。RPC-N と RPC-TNC の技術資料に、その行はありません。一つの順位にはしません。
- 結合は、5/8-24 か、7/16-28 か、です。直接はロックしません。変換アダプタは、両端の系列と、アダプタ自身の周波数と、両端の締め方をセットで見ます。型番が案内の列に無いときは、作りません。
- 締付は、端の系列の行です。0.70–1.10 N·m、1.5 N·m、8–12 inch-pounds を、TNC の 0.46–0.69 N·m や 0.51–0.67 N·m と、一つの値にはしません。試験の 1.70 N·m を、推奨の嵌合トルクには読みません。インチポンドを、このページで N·m には換算しません。
- 振動は、ねじという言葉と、試験条件の文字を、別々に見ます。開いた Amphenol のページでは、N 型も TNC も Method 204 の Condition B です。RPC-TNC は Condition D です。RPC-N は IEC 61169-1 の細分箇条です。この文字を、耐振動の順位にはしません。
- 屋外は、weatherproof という語と、IP67 を選べるという文だけでは決めません。ガスケットの有無は、その製品の図面です。着脱の回数が多い場所では、バヨネットの文を先に見ます。それだけで、周波数と電力の行は決まりません。
