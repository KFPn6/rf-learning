# N型の50Ωと75Ωの違いと見分け方

N 型は、ねじ結合の同軸コネクタです。IEC 61169-16:2006 の Webstore の題は、外導体の内径 7 mm（0,276 in）、ねじ結合、特性インピーダンス 50 ohms（75 ohms）、type N です。IEC は小数点をコンマで書きます。このページの地の文では 0.276 in とします。同じ type N という名前の中に、50 Ω と 75 Ω があります。ねじが共通でも、二つの資料は、互いに嵌合する相手ではない、と書きます。

ここにある数字は、Webstore の公開案内と、計測器メーカーのアプリケーションノートと、メーカーのシリーズ資料から取った学習用の目安です。個別の製品が保証する値ではありません。同じ名前でも、資料が複数の周波数を置きます。平均して一つの上限にはしません。ピン径のミリメートルは、資料で差があるため、このページでは転載しません。

径と比誘電率の式、50 Ω と 75 Ω を一つの境目でつないだときの反射は [特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) です。SMA とのねじの呼び、外径、電力の行は [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) です。系列の早見は [コネクタの種類]({{ '/learn/connector-types/' | relative_url }})、上限を平均しない読み方は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。バヨネットの 50 Ω と 75 Ω は [BNC の 50 Ω と 75 Ω]({{ '/learn/bnc-50-75/' | relative_url }})、宅内のねじの 75 Ω は [F型コネクタ]({{ '/learn/f-type/' | relative_url }}) です。名前の話は [第8話]({{ '/manga/08-paul-neill/' | relative_url }}) です。会話はフィクション演出です。

## 外導体の内径と、ねじ

IEC 61169-16:2006 の Webstore の題は、外導体の内径 7 mm（0,276 in）の、ねじ結合の高周波同軸コネクタです。特性インピーダンスは 50 ohms（75 ohms）、通称は type N、と題が続きます。公開案内は、ピンとソケット、低から中の電力、詳細仕様を書くための情報と規則、と書きます。ワットの行は、その案内にはありません。

0.276 × 25.4 = 7.0104 です。この計算は、題のインチ表記をミリメートルへ置いたもので、表の公差ではありません。公差表は、開いた Webstore の範囲にはありません。7.0104 を、最大や最小の端としては読んでいません。

結合の呼び 5/8-24 UNEF は、同じ type N の界面の表を [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) が置いています。このページが開いた Webstore の公開案内は、ねじ結合、までです。5/8-24 の文字は、その案内にはありません。規格本文の有償版から、ねじの表をここへは写していません。

Rohde & Schwarz のアプリケーションノート 1MA99 は、75 Ω と 50 Ω のタイプ N が共通のねじ径を持つ、と書きます。日本語版の語はネジ径です。呼びが 5/8-24 だ、とは、その注は書いていません。共通のねじ径を、嵌合してよい、には読みません。次の節です。

SMA の 1/4-36 は、この 5/8-24 とは山が掛かり合う相手ではありません。外導体内径の題も、7 mm と 4.13 mm で違います。読み分けは [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) です。同じサイトが中〜大電力の例に置く 7/16 も、別のねじです。[7/16と4.3-10]({{ '/learn/7-16-43-10/' | relative_url }}) です。

## ねじが共通でも、嵌合してはいけない

嵌合の文は、資料で主語が違います。一つの「すべてが嵌合する」には読みません。

Webstore の公開案内は、50 Ω の type N に三つの版が含まれ、各版は互いに嵌合できる、と書きます。版の名前と、GHz の数字は、その案内にはありません。grade の呼びと、11、12、18 の行は [コネクタの種類]({{ '/learn/connector-types/' | relative_url }}) と [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) です。そちらの行を、この公開案内の更新には読みません。三つの版が互いに嵌合できる、という文の主語は 50 Ω です。75 Ω との嵌合を、その文は書いていません。題の括弧（75 ohms）を、嵌合できる相手の一覧には読みません。

Rohde & Schwarz は、75 Ω と 50 Ω は共通のねじ径を持っていても適合性は無い、と書きます。英語版の語は not compatible です。Radiall の N / Composite N / N 18 GHz のシリーズ資料は、50 Ω と 75 Ω は NOT INTERMATEABLE で、接続面の破壊に至る、と書きます。この警告は、導入と、界面の節にあります。適合性が無い、と、接続面の破壊、は、別の資料の語です。一つの動詞にはまとめません。どちらも、嵌合してよい、とは書いていません。

同じ Radiall の導入は、複合材料のレセプタクルについて、標準の N と嵌合し、後方互換のため、とも書きます。この文の相手は、標準の N です。50 Ω と 75 Ω が嵌合する、という文ではありません。上の NOT INTERMATEABLE と、同じページの中に両方あります。複合材料の行を、75 Ω との嵌合の許可には読みません。

N 18 GHz の節は、すべての 50 Ω の N と嵌合する、と書きます。50 Ω 同士の文です。75 Ω を、この「すべて」へは入れません。

ねじを回して山が掛かることと、中心まで合わせてよいことは、別です。試して挿し、傷むかどうかでオームを確かめる手順にはしません。

## オスピンと、メスソケット

Rohde & Schwarz は、50 Ω のタイプ N のオスピンは、75 Ω のタイプ N のメスソケットより大きい、と書きます。これらのコネクタを接続すると、コネクタの損傷を招く、と続きます。英語版は、damage if connected together です。大小の関係と、接続したときの損傷までが、その注です。ピンの径のミリメートルは、注にありません。このページは、その穴をほかの資料の数字で埋めていません。

Radiall は、50 Ω と 75 Ω で界面の節を分け、互いに嵌合せず、接続面の破壊に至る、と書きます。寸法表と図は転載していません。75 Ω の界面の節には、表とは別に、脚注の寸法の書き方もあります。数値は写していません。一つのカタログの一節を、すべての個体のピン径にはしません。

75 Ω の N の接続面は、開いた資料のあいだで、一つの寸法に揃っていません。Rohde & Schwarz は大小だけを書きます。Radiall は界面を節で分け、脚注に別の書き方を残します。時期や製造者が違えば寸法が一つに揃う、とまとめた文書は、このページでは開いていません。ピン径を、一つの幅としては書きません。目視の太さを、その未転載の公差の測定にはしません。

## 使用周波数の目安

周波数は、学習用の目安です。製品が保証する上限ではありません。文書が違えば、行も違います。

Rohde & Schwarz の 1MA99 は、タイプ N（50 Ω）の節で、最大周波数を通常型 11 GHz、精密型 18 GHz とします。絶縁体は、通常型が PTFE、精密型が空気、と書きます。前文は、耐久性、耐候性、中サイズ、11 GHz までの対応性能、として開発された、と書きます。精密型は空気絶縁体で、18 GHz まで使用できる、と続きます。この 11 と、節の見出しの通常型 11 は、同じ節の中の言い方です。18 も、精密型の行と、前文の行で同じ節です。

同じノートの冒頭の図は、Type N を 11 GHz、Precision N を 18 GHz に置きます。節 3.1 の二つの数字と、図の二つの数字は、一つの文書の中で揃います。図には、ほかの系列の棒もあります。BNC の棒は 4 GHz です。75 Ω のタイプ N の上限 4 GHz は、節 3.1 の注にあり、その図の棒ではありません。図の BNC の 4 と、注の 75 Ω の N の 4 を、一つのコネクタの上限にはしません。

75 Ω の注は、上限周波数は 4 GHz、と書きます。通常型の 11 でも、精密型の 18 でもありません。日本語版（2012-12-12、1MA99、Version 1.0）と、英語版（2015 年 4 月、1MA99_2e）で、この節の 11、18、4 は同じです。版の年が違うことを、数字の更新には読んでいません。このページは、二つの版のほかの節がすべて同じだ、とは確認していません。

Radiall の導入は、50 Ω を、標準の N が DC–11 GHz、N 18 GHz が DC–18 GHz、75 Ω を DC–1.5 GHz とします。特性の節も、N 50 Ω が DC–11 GHz、N 18 GHz が DC–18 GHz、N 75 Ω が DC–1.5 GHz です。導入と特性の節は、同じ資料の中で揃います。1.5 を、Rohde & Schwarz の 4 の誤記には読みません。4 を、Radiall の 1.5 の更新にも読みません。

11 と 18 は、二つの資料にどちらも現れます。呼びは違います。Rohde & Schwarz は通常型と精密型、Radiall は標準の N と N 18 GHz です。数字が同じでも、文書は別です。一つの「N の上限は 18 GHz」にはまとめません。75 Ω の 4 と 1.5 は、数字そのものが違います。

IEC の Webstore の公開案内には、GHz の数字がありません。grade の 11、12、18 を、このページの 4 や 1.5 へは平均しません。そちらの grade は、別ページが公開サンプルから置いた行です。カットオフの式へ 7 mm を入れる計算も、このページではしていません。読み方は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。

## 用途

用途も、資料の文のまま置きます。一つの「50 Ω は無線、75 Ω は放送」にはまとめません。

Rohde & Schwarz の 1MA99 は、測定機器で使う同軸コネクタの選定と取り扱いの案内です。タイプ N の節は、耐久性、耐候性、中サイズ、11 GHz までの対応性能、と書きます。精密型は、空気絶縁体で 18 GHz まで、です。この節を、放送用の 75 Ω、とは書いていません。会社案内の欄に放送の語があっても、75 Ω の N の用途の行には読みません。

Radiall の導入は、シリーズの用途に、無線通信、民生と軍用の無線通信機器、対抗手段、海軍の機器、産業、を置きます。この箇条は、50 Ω と 75 Ω の周波数を並べた導入の中にあります。オームごとに箇条を分けてはいません。無線通信の語を、50 Ω だけのものには読みません。75 Ω だけのものにも読みません。

同じ資料の N 18 GHz の節は、中から高の電力と、精密なマイクロ波の測定器に向く、と書きます。Webstore の公開案内は、低から中の電力、です。低から中、と、中から高、を一つの電力にはしません。ワットの行は、このページでは置いていません。[N型とSMA]({{ '/learn/n-sma/' | relative_url }}) です。

Radiall の N 75 Ω の製品節は、ケーブルの例に RG59、RG62、RG6、RG11、RG179 を置きます。部品番号の表は転載していません。ケーブルの呼びが並ぶことを、映像・放送専用のコネクタだ、という文には読みません。コネクタのオームと、ケーブルのオームは、別の指定です。RG-59 の題の 75 Ω は [BNC の 50 Ω と 75 Ω]({{ '/learn/bnc-50-75/' | relative_url }}) が、ケーブルの仕様書から置いています。

映像と放送で、このサイトが 75 Ω の界面として分けているのは、バヨネットの BNC と、宅内のねじの F 型です。N 型の 75 Ω を、その二つの言い換えにはしません。F 型の周波数の区分は [F型コネクタ]({{ '/learn/f-type/' | relative_url }}) です。50 Ω と 75 Ω が線路として分かれる理由は [特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) です。

## BNC の 50 Ω と 75 Ω との違い

両方とも、50 Ω と 75 Ω が同じ系列の名前の中にあります。嵌合の読みは違います。

BNC は、バヨネットです。確認した規格では、外導体内径の呼びがどちらも 6.5 mm で、嵌合ピン径の行も同じ幅です。資料は、機械的に嵌合しうる、壊さずに嵌合できる、制限なく相互嵌合する、と書きます。中心コンタクトの径が近く、完全に嵌合しうる、という側です。インピーダンスを混ぜると、境目の反射は残ります。ピン径、誘電体、反射の計算は [BNC の 50 Ω と 75 Ω]({{ '/learn/bnc-50-75/' | relative_url }}) です。このページは、その表と、0.2 の計算を写していません。

N 型は、ねじです。Rohde & Schwarz は、ねじ径が共通でも適合性は無く、50 Ω のオスピンは 75 Ω のメスソケットより大きく、接続すると損傷する、と書きます。Radiall は、接続面の破壊に至る、と書きます。BNC の「非破壊で嵌合しうる」を、N 型へ写しません。N 型のねじが回ることを、BNC のバヨネットが留まることと同じ安全の側には置きません。

反射の式は、どちらの系列でも、オームが違う境目の話です。N 型では、その反射を見るために 50 Ω と 75 Ω を嵌合する、という順にはしません。資料が先に書くのは、損傷と、接続面の破壊です。形だけを合わせた変換が測定に残す不整合は、[特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) です。

## 見分けのポイント

見るのは、表示と、図面と、データシートのオームです。

ねじの山が同じに見えること、外形が同じ型の N に見えることでは、50 Ω と 75 Ω は決まりません。Webstore の題の外導体内径は、50 ohms（75 ohms）を一つの題に置いています。7 mm を、50 Ω だけのものとしては読んでいません。共通のねじ径は、Rohde & Schwarz が、適合性が無い、と書くときの前提です。

金色に見えること、白い樹脂が見えることだけでは決まりません。Radiall の複合材料のレセプタクルには、色分けが任意、という行があります。その行は、75 Ω の印だ、とは書いていません。色を、オームの規則にはしません。

ピンの太さを目で見て、一つのミリメートルと比べる手順にもしません。比較する数値が、このページにはありません。75 Ω の接続面を、一つの寸法にまとめていない、という前の節のままです。

試して嵌合し、入るかどうかで分ける手順にもしません。入る前に、資料は損傷と破壊を書いています。

## 選定するときに見ること

- 図面で、50 Ω か 75 Ω か、プラグかジャックか、を見ます。N 型、という一語では注文しません。ねじが 5/8-24 に見えることだけでは、オームは決まりません。呼びの置き場所は [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) です。
- 50 Ω と 75 Ω は、嵌合する相手ではありません。Rohde & Schwarz は損傷、Radiall は接続面の破壊、と書きます。Webstore が互いに嵌合できると書くのは、50 Ω の三つの版のあいだです。
- 周波数は、資料の行のまま置きます。Rohde & Schwarz の 50 Ω は通常型 11 GHz、精密型 18 GHz、75 Ω は 4 GHz です。Radiall の 50 Ω は標準が DC–11 GHz、N 18 GHz が DC–18 GHz、75 Ω は DC–1.5 GHz です。4 と 1.5、11 と 18 を、一つの上限にはしません。図の BNC の 4 GHz を、75 Ω の N の 4 GHz には読みません。
- ピン径のミリメートルは、このページでは選んでいません。データシートの界面を、その製品の行として見ます。一つの幅へ平均した寸法では注文しません。
- 用途は、測定器の案内の耐久性・耐候性・中型と、シリーズ資料の無線通信などの箇条を、別の文のまま見ます。映像と放送の 75 Ω は、[BNC]({{ '/learn/bnc-50-75/' | relative_url }}) と [F 型]({{ '/learn/f-type/' | relative_url }}) です。
- 電力は、Webstore の低から中、と、Radiall の N 18 GHz の中から高、を一つの語にはしません。ワットは [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) です。
- SMA や 7/16 へシリーズをまたぐときは、変換アダプタの両端と、アダプタ自身の周波数を見ます。50 Ω の N と 75 Ω の N のあいだを、ねじが共通だから直結、にはしません。
