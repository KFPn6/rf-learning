# N型と4.3-10の違いと使い分け

N 型と 4.3-10 は、通信や測定の現場で並ぶ同軸コネクタです。掛かる山は違います。IEC 61169-16:2006 の題は、外導体内径 7 mm（0.276 in）、ねじ結合、特性インピーダンス 50 Ω（75 Ω）、type N です。IEC 61169-54:2021 の題は、外導体内径 10 mm、特性インピーダンス 50 Ω、series 4,3-10 です。IEC はコンマで 4,3-10 と書きます。Rosenberger と Amphenol RF の製品案内は、ピリオドで 4.3-10 と書きます。このページは、検索で見る N 型と 4.3-10 を見出しに残し、規格の呼びは資料の文字のまま置きます。

結合は、N 型の開いた資料がねじ、4.3-10 の規格の題がねじ、手締め、クイックロックの三つです。ねじの呼びは、N 型のプレビューが 5/8-24 UNEF、4.3-10 のプレビューと Rosenberger の界面が M20×1 です。5/8-24 のナットは、M20×1 には進みません。系列をまたぐときは、変換アダプタです。

ここにある数字は、公開の規格の題と適用範囲、公開プレビューの寸法の行、メーカーの製品案内と技術資料、計測器メーカーのアプリケーションノートから取った学習用の目安です。個別の製品が保証する値ではありません。同じ名前でも、規格の上限と、シリーズ資料の周波数範囲と、標準と精密は、別の数字です。平均して一つの上限にはしません。

系列の早見は [コネクタの種類]({{ '/learn/connector-types/' | relative_url }}) です。同じねじ同士の SMA との呼びの違いは [N型とSMA]({{ '/learn/n-sma/' | relative_url }}) です。ねじの N 型と、バヨネットの BNC は [N型とBNC]({{ '/learn/n-bnc/' | relative_url }}) です。同じねじでも山が 7/16-28 の TNC は [N型とTNC]({{ '/learn/n-tnc/' | relative_url }}) です。7/16 との嵌合、電力、PIM、トルクは [N型と7/16]({{ '/learn/n-7-16/' | relative_url }}) です。7/16 と 4.3-10 のあいだは [7/16と4.3-10]({{ '/learn/7-16-43-10/' | relative_url }}) です。このページは、7/16 のねじの呼びと推奨トルクの詳細を写しません。N 型の 50 Ω と 75 Ω の見分けと、誤嵌合の注意は [N型の50Ωと75Ω]({{ '/learn/n-50-75/' | relative_url }}) です。このページは、N 型に両方があることと、その導線にとどめます。上限を平均しない読み方は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。帯域名との対応は [規格・周波数]({{ '/spectrum/' | relative_url }}) です。N 型も 4.3-10 も、コネクタの呼びです。帯域名ではありません。同じ現場で並ぶ NEX10 とのあいだは [4.3-10とNEX10]({{ '/learn/43-10-nex10/' | relative_url }}) です。7/16 と NEX10 のあいだは [7/16とNEX10]({{ '/learn/7-16-nex10/' | relative_url }}) です。このページは、その嵌合と呼びの詳細を写しません。

## ねじの呼びと、外導体の径

IEC 61169-16:2006 の適用範囲は、ピンとソケットの高周波同軸コネクタで、結合はねじ、用途の文は低から中の電力です。通称は type N、と書きます。50 Ω には三つの grade があり、互いに嵌合しうる、と続きます。Webstore の公開案内は、題と、低から中の電力と、50 Ω の三つの版が互いに嵌合できること、までです。GHz の文と、5/8-24 の文字は、その案内にはありません。

ピン中心の表で、a は 7.00 nom、インチ欄は 0.2756 nom、注は直径です。c は 5/8-24 UNEF-2B で、注は ISO 263 のねじです。同じプレビューは、インチ寸法が原寸で、ミリメートルは必ずしも厳密ではない、と書きます。題の括弧は 0.276 in です。ソケット中心の表は、開いた 11 ページの範囲にはありません。ソケット側の 5/8-24 UNEF-2A を、このプレビューの文字としては置いていません。

ねじの両側は、Rosenberger の RPC-N 50 Ω の技術資料で置きます。プラグの F は 5/8-24UNEF-2B、ジャックの F は 5/8-24UNEF-2A です。2B は内ねじ、2A は外ねじの等級です。B は両列とも 6.99–7.01 mm です。題の 7 mm、表の 7.00 nom、B の 6.99–7.01 を、一つの径にはしません。プラグの G は hex 19 です。ジャックの G は、その表にありません。

IEC 61169-54:2021 の開いたプレビューの適用範囲は、外導体内径 10 mm、50 Ω、series 4,3-10、結合はねじ、手締め、クイックロック、上限の動作周波数は 6 GHz、無線通信と無線ネットワーク向け、と書きます。Webstore の公開案内も、この範囲を要旨に置きます。M20×1 の文字は、その要旨にはありません。ねじの呼びは、開いたプレビューの寸法の行で置きます。ピン中心の o は M20×1、公差 6H、ねじ、です。ソケット中心の s は M20×1、公差 6g、ねじ、です。6H と 6g を、別の呼び径には読みません。ピン側の k は 10.0 nom、注は直径です。ソケット側の m は 9.8–10.2、注は直径です。中心側は、ピンの j とソケットの l がどちらも 4.35 nom で、注は 50 Ω の公称インピーダンスのための直径、と書きます。ピン側の p は 22 nom、注はレンチのサイズです。ソケット側の表に、このページが読んだレンチサイズの行はありません。プレビューの表はコンマ表記です。このページは、寸法の数字をピリオドで置きます。呼びの 4,3-10 のコンマと、寸法の 4.35 のコンマを、同じ丸めだ、とは書いていません。

Rosenberger の 4.3-10 シリーズ技術資料は、界面を IEC 61169-54 とします。A は、オスもメスも 4.35 nom です。オスの B は 10.00 nom、メスの B は 9.80–10.20 です。D は、オスもメスも M 20 x 1 と書きます。6H と 6g は、そのセルにはありません。オスの G は SW 22 です。メスの G は、その表にありません。題の 10 mm、プレビューの 10.0 nom、オスの B の 10.00、メスの 9.8–10.2 と 9.80–10.20 を、一つの径にはしません。プレビューの 22 nom と、SW 22 を、一つの開口の更新にも読みません。呼びの 4.3 は、中心側の 4.35 の隣にあります。呼びの 10 は、題の外導体内径と、B と k と m の側にあります。4.35 を、資料が 4.3 へ丸めた、とは書いていません。並びとして置きます。

N 型の 7 mm は、外導体の内径です。4.3-10 の 4.35 は、中心側の行です。測っている場所が違います。5/8 インチは 0.625 インチで、0.625 × 25.4 = 15.875 mm です。これは N 型のねじの呼び径の換算であり、hex 19 でも、SW 22 でも、M20 の呼び径でもありません。

5/8-24 のナットは、M20×1 の外ねじには進みません。M20×1 のナットも、5/8-24 の外ねじには掛かりません。インチの山と、メートルねじは、掛かり合う相手ではありません。山が合わない相手を、力で回しません。

## 結合

N 型の結合は、開いた資料ではねじです。IEC の題は screw coupling です。Rosenberger の RPC-N の製品案内は screw-on、技術資料の F は 5/8-24 UNEF です。Amphenol の特徴は 5/8-24 のねじ、仕様表の結合の欄は Threaded です。手締めと、クイックロックの行は、このページが開いた N 型の案内にはありません。無い行を、4.3-10 の三種類で埋めません。

4,3-10 の結合は、IEC の適用範囲が三つ書きます。ねじ、手締め、クイックロックです。開いたプレビューの図の見出しは、ねじと手締めまでです。クイックロックの図は、そのプレビューの最後のページにはありません。ソケットの表の注は、前面の縁と溝をクイックロックの取り付け用、と書きます。図が無いことを、クイックロックの結合が適用範囲に無い、とは読みません。適用範囲の文が三つ書いています。

Rosenberger の製品案内も三つで、screw（HEX）、hand-screw、push-pull / quick-lock です。push-pull と quick-lock は、同じ案内が一つの型に並べる呼びです。別の第四の界面には読みません。同じ案内は、ユニバーサルなジャックが、三種類のプラグすべてと嵌合する、と書きます。三種類のプラグが、ジャックを介さずに互いへ直接嵌合する、とは書いていません。この互換は、4.3-10 の内側の話です。N 型の 5/8-24 へは及びません。

ねじ（HEX）の推奨は 5 N·m で、厳しい環境向け、と書きます。手締めは、意図しない緩みへの抜け止めがあり、トルクは無い、と書きます。クイックロックは、工具が要らない、と書きます。三つの文を、一つの「屋外ならねじ」にはまとめません。5 N·m を、手締めの指定には読みません。

Amphenol の 4.3-10 の概要は、hex-wrench、hand-tight、push-pull と書きます。特徴は、hand-tight、wrench、quick-connect push-pull と書きます。同じページの仕様表は、結合の欄を Threaded だけにします。概要の三つを、仕様表の Threaded の更新には読みません。仕様表の Threaded を、概要の誤記にも読みません。二つの書き方のまま置きます。

4.3-10 のクイックロックは、QMA のクイックロックではありません。QMA は別の外導体内径で、SMA のねじとは嵌合しない案内です。[QMAとSMA]({{ '/learn/qma-sma/' | relative_url }}) です。

## 周波数の目安

周波数は、学習用の目安です。製品が保証する上限ではありません。

N 側で、このページが並べる行は次です。IEC 61169-16:2006 の適用範囲は、grade 2 をおよそ 12 GHz、grade 1 の一部を 18 GHz まで、grade 0 を 18 GHz まで、とします。Webstore の公開案内に、この GHz の文はありません。Amphenol の標準は DC–11 GHz、拡張は DC–18 GHz です。Rohde & Schwarz の 1MA99 は、タイプ N（50 Ω）の最大周波数を、通常型 11 GHz、精密型 18 GHz、と書きます。英語版（2015 年 4 月、1MA99_2e）と、日本語版（2012-12-12、Version 1.0）で、この 11 と 18 の並びは同じです。二つの版の全文が同一だとは、このページでは確認していません。Rosenberger の RPC-N の製品案内は、50 Ω を 18 GHz まで、75 Ω を 4 GHz まで、とします。技術資料の 50 Ω の行は DC to 18 GHz です。4、11、12、18 を平均しません。

4.3-10 側の行は次です。IEC 61169-54:2021 の適用範囲は、上限の動作周波数を 6 GHz とします。Webstore の要旨にも、この 6 GHz はあります。Rosenberger の製品案内とシリーズ資料の周波数範囲は、DC–12 GHz です。同じ技術資料のリターンロスは、DC–4 GHz で 36 dB 以上、4–6 GHz で 32 dB 以上までです。12 GHz までのリターンロスの行は、その資料にはありません。製品案内のリターンロスも、ケーブルコネクタのストレートとして、同じ 36 dB と 32 dB で、6 GHz までです。ストレートという限定は、製品案内の行にあります。技術資料の行には、その限定の文字はありません。36 と 32 を、限定の有無を消した一つの反射にはしません。Amphenol の仕様表の周波数範囲は DC–6 GHz です。同じ表の VSWR は、DC–4 GHz で 1.032（−36 dB）、4–6 GHz で 1.052（−32 dB）です。括弧の dB は、そのページが併記しています。このページで VSWR から換算し直した数字ではありません。6 を、Rosenberger の周波数範囲の DC–12 GHz の誤記には読みません。12 を、IEC と Amphenol の周波数範囲の更新にも読みません。

RF リークも、端が違います。RPC-N は 1 GHz まで 90 dB 以上です。Amphenol の N は、DC–3 GHz で −90 dB Max と書きます。以上と、Max の符号を、一つの遮蔽にはしません。4.3-10 のシリーズ資料は、ねじが DC–6 GHz で 110 dB 以上、工具を使わないプラグ（手締めとクイックロック）が DC–3 GHz で 90 dB 以上、3–6 GHz で 70 dB 以上です。12 GHz を、このリークの行の先へ延ばしません。Amphenol の 4.3-10 は、DC–3 GHz で −120 dB Max と書きます。110 以上と、−120 Max を、一つの差には引きません。周波数の端も、符号の書き方も違います。

1MA99 の図のラベルに、4.3-10 はありません。目次の 4.3 は、英語版が Cleaning、日本語版がクリーニングです。節の番号です。series 4,3-10 でも、製品案内の 4.3-10 でもありません。図の前の文は、多くのコネクタが外導体内径で呼ばれる、と書きます。その文を、4.3-10 の中心側 4.35 の説明には読みません。4.3-10 の題が外導体内径として置くのは 10 mm です。N 型の題が外導体内径として置くのは 7 mm です。

1MA99 は、違う型を一つの系で使うときは、周波数範囲が最も低い型が、系の周波数範囲を決める、と書きます。英語版と日本語版で、この文の趣旨は揃います。N 型の 18 GHz の行と、4.3-10 の 6 GHz や 12 GHz の行を、一つの系の上限にはしません。アダプタ自身の行も、別に見ます。後の節です。カットオフの計算へ寸法を入れる読み方は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。このページは、7 mm と 10 mm をその計算へ入れて、11 GHz や 12 GHz の説明にはしていません。反射の読み方は [VSWR とリターンロス]({{ '/learn/vswr-return-loss/' | relative_url }}) です。

## 電力の目安

電力も、資料の文のまま置きます。ワットを平均して、一つの上限にはしません。形容の語も、一つの「N 型は中電力、4.3-10 は大電力」にはまとめません。

IEC 61169-16 の適用範囲は、low to medium power、です。このページは、低から中の電力、と置きます。ワットの数字は、その文にはありません。IEC 61169-54 の開いた適用範囲に、ワットの数字はありません。無いワットを、後の 500 W で埋めません。

Amphenol の N の仕様表は、300 W @ 10 GHz @ 25 °C です。注は、これらの特性は典型値で、すべてのコネクタには当てはまらない、です。RPC-N の技術資料に、電力の行はありません。無い行を、300 W で埋めません。

4.3-10 のシリーズ資料は、90 °C、高度 3000 m で、2 GHz の 500 W です。Amphenol の仕様表は、500 W @ 2 GHz @ 90 °C です。そのセルに、高度はありません。500 と 500 を、高度の有無を消した一つの電力にはしません。300 と 500 も、周波数の条件が違うので、系列の倍率にはしません。300 を 2 GHz へ、500 を 10 GHz へは写しません。

電圧も、単位の書き方が分かれます。一つの比にはしません。Amphenol の N は連続 500 V rms、耐電圧 1500 V rms です。RPC-N は、試験電圧 2500 V rms、動作電圧 1000 V rms、またはケーブルの制限、です。Amphenol の 4.3-10 は連続 500 V rms、耐電圧 2500 V rms です。Rosenberger の 4.3-10 は、試験電圧 2500 V rms、動作電圧 500 V rms です。N の Amphenol の連続 500 と、4.3-10 の Rosenberger の動作 500 と、Amphenol の 4.3-10 の連続 500 を、一つの 500 にはしません。1500 と 2500 も、一つの耐電圧にはしません。

## PIM

PIM の仕組みは [深掘り]({{ '/learn/master/' | relative_url }}) です。この節は、開いた資料が置く行だけを見ます。7/16 の −155 dBc の行は、ここへ写しません。[7/16と4.3-10]({{ '/learn/7-16-43-10/' | relative_url }}) と [N型と7/16]({{ '/learn/n-7-16/' | relative_url }}) です。

N 側で、数字が読めたのは Amphenol の仕様表です。−166 dBc、入力は 2 × 43 dBm、と書きます。周波数の幅は、そのセルにはありません。RPC-N の技術資料に、PIM の行はありません。1MA99 の英語版と日本語版に、PIM の語は、このページでは見つかっていません。無い行を、−166 で埋めません。IEC の開いた適用範囲にも、dBc の行はありません。

4.3-10 のシリーズ資料は、二つ書きます。≤ −160 dBc（2 × 46 dBm）と、≤ −166 dBc（2 × 43 dBm）です。どちらも 0.4–4 GHz です。製品案内は、同じ 2 × 43 dBm の側を ≥ 166 dBc と書きます。負号付きの −166 dBc 以下と、大きさを正で書く 166 dBc 以上は、この二つの資料では同じ試験条件の書き方の差として置きます。−160 と −166 は、入れる電力が 2 × 46 dBm と 2 × 43 dBm で違います。一つの PIM にはしません。製品案内は、PIM がトルクによらず低い、とも書きます。技術資料の −160 と −166 を、その文の定義には読みません。

Amphenol の仕様表は、別の単位です。2 × 20 W で −166 dBc、2 × 40 W で −160 dBc、どちらも 0.4–4 GHz です。特徴の箇条は ≤ –166 dBc @ 2×20 W と書き、その箇条に周波数の幅はありません。要点の文は ≥ –166 dBc と書き、その文に電力と周波数の幅はありません。別の要点は 500 W at 2 GHz で、これは電力の行です。PIM の dBc には読みません。20 W と 43 dBm、40 W と 46 dBm を、このページで換算して一つの試験にはしません。単位の書き方が違う行のまま置きます。−166 の文字が N 型の Amphenol と 4.3-10 の資料に出ても、入力の単位と、周波数の幅の有無が違います。一つの成績にはしません。

## 屋外と、着脱と、シール

屋外、着脱、シールも、資料の文のまま置きます。一つの「N 型は計測、4.3-10 は屋外」にはまとめません。

外導体内径の題は、N 型が 7 mm、4.3-10 が 10 mm です。これは胴の外径ではありません。1MA99 は、タイプ N を、耐久性があり、耐候性があり、中サイズ、と書きます。これは、開発したときの要求の文です。すべての個体が、ある IP 等級だ、とは書いていません。7 mm と 10 mm の差を、中サイズの測定結果には読みません。英語版は Type N (Navy) と書きます。日本語版も、タイプ N（Navy）と書きます。このページは、その展開を採りません。

4.3-10 の Rosenberger の製品案内は、IP68（25 m、1 hours）と書きます。シリーズ資料は、嵌合した対の保護等級を IEC 60529 の IP68（1h / 25 m）とします。1 hours と 1h を、別の試験時間には読みません。書き方の差として置きます。25 m は、両方の行にあります。材料欄のガスケットはゴムです。動作温度は −55 °C から +90 °C です。Amphenol の 4.3-10 は、概要と特徴と要点が、未嵌合で IP67、と書きます。同じページの仕様表は、Interface Sealing を、嵌合状態で IP68、とします。未嵌合の IP67 と、嵌合の IP68 を、一つの等級にはしません。温度は −40 °C から +85 °C です。−55 から +90 と、−40 から +85 を、一つの範囲にはしません。IP68 という文字だけで、Rosenberger の 25 m、1 時間と、Amphenol の嵌合時の等級が同じ試験だ、とは読みません。

着脱の速さも、一つの秒数にはしません。N 型の開いた資料はねじです。4.3-10 は、ねじに加えて手締めとクイックロックがあります。BNC の約四分の一回転を、どちらのナットへも使いません。1MA99 の取り扱いは、相手どうしを回さず、ナットだけを指で回し、そのあと校正済みのトルクレンチで締め切る、と書きます。この手順を、N 型だけのものには読みません。4.3-10 の手締めは、製品案内がトルクなし、と書きます。クイックロックは、工具なし、と書きます。指で回し始めることと、手締めにトルクを書かないこととは、同じ指定ではありません。嵌合回数の下限は、RPC-N が 500 以上、Amphenol の N が 500 以上、Rosenberger の 4.3-10 が 100 以上、Amphenol の 4.3-10 が 100 以上です。回数の下限が、傷んだあともその回数まで使える、という意味にはなりません。500 と 100 を、耐候の倍率にはしません。

最小ピッチで、4.3-10 の資料が置く行は 25.4 mm 以上です。製品案内とシリーズ資料のどちらにもあります。ピッチは、並べて実装するときの最小の間隔の行です。コネクタ一本の全長ではありません。RPC-N の技術資料に、ピッチの行は、このページでは見つかっていません。無い行を、25.4 mm で埋めません。7/16 との大きさの文は、このページでは繰り返しません。[7/16と4.3-10]({{ '/learn/7-16-43-10/' | relative_url }}) です。

Amphenol RF の 4.3-10 アダプタの案内は、シリーズ内とシリーズ間で、相手に N 型を含みます。見出しの数は、4.3-10 to N-Type Adapters が 4 Parts です。開いたその見出しのページと、N-Type to 4.3-10 Adapters のページに、型番は見当たりませんでした。無い型番を、このページでは作りません。同じ案内は、動作を 6 GHz まで、場合により 12 GHz まで、と書きます。6 と 12 を、一つのアダプタの上限にはしません。53S164-K00N1 の DC–12 GHz の更新にも読みません。IP67 は、選択モデルの行です。すべてのアダプタの等級ではありません。

## 選定するときに見ること

- 図面で、N 型か 4.3-10 か、プラグかジャックか、4.3-10 ならねじか手締めかクイックロックか、を見ます。大きいねじ、という一語では注文しません。N 型なら、50 Ω か 75 Ω かも見ます。見分けは [N型の50Ωと75Ω]({{ '/learn/n-50-75/' | relative_url }}) です。
- 外導体内径の呼びは、7 mm と 10 mm です。技術資料の B は、N 型が 6.99–7.01 mm、4.3-10 のオスが 10.00 nom、メスが 9.80–10.20 です。中心側の 4.35 を、N 型の外導体内径 7 mm とは別の寸法として置きます。
- ねじは、5/8-24 UNEF と M20×1 です。プレビューの 6H と 6g は、同じ M20×1 の等級です。N 型の 2B と 2A の代わりにはなりません。
- 周波数は、行のまま置きます。N 型は、IEC のおよそ 12 GHz と 18 GHz、Amphenol の DC–11 GHz と DC–18 GHz、1MA99 の 11 GHz と 18 GHz、RPC-N の 18 GHz と 4 GHz です。4.3-10 は、IEC と Amphenol の周波数範囲が 6 GHz まで、Rosenberger の周波数範囲が DC–12 GHz、リターンロスの行が 6 GHz までです。変換アダプタ 53S164-K00N1 は DC–12 GHz です。Amphenol のアダプタ案内は、6 GHz まで、場合により 12 GHz まで、と書きます。
- 締付は、端の行です。N 型は、0.70–1.10 N·m、8–12 inch-pounds、1.5 N·m が、別の資料の行です。4.3-10 のねじは 5 N·m、手締めはトルクなし、クイックロックは工具なし、です。試験の 1.70 N·m と 8 N·m を、推奨には読みません。約 5 N·m を、手締めには使いません。
- PIM は、N 型で数字が読めたのが Amphenol の −166 dBc（2 × 43 dBm）です。4.3-10 は、シリーズ資料の二つの行と、Amphenol の 2 × 20 W と 2 × 40 W の行です。アダプタ 53S164-K00N1 は、版により 168 dBc と 155 dBc です。条件を消して引きません。
- 7/16 との使い分けは、[N型と7/16]({{ '/learn/n-7-16/' | relative_url }}) と [7/16と4.3-10]({{ '/learn/7-16-43-10/' | relative_url }}) です。SMA、BNC、TNC は、それぞれのページです。
