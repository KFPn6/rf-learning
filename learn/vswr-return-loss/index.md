# VSWR とリターンロス

同軸ケーブルアッセンブリの成績表で、先に名前が出る指標を、一ページにまとめます。反射の側が、反射係数、VSWR、リターンロスです。先へ届く信号がどれだけ減るかが、挿入損失です。公開資料の式から組み立てた学習用の読み方であり、個別製品の保証値ではありません。

短い定義は [用語集]({{ '/glossary/' | relative_url }}) です。特性インピーダンスそのものの式と、50 Ω と 75 Ω を直接つないだときの 0.2 は [特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) です。数字の行だけを引くなら [数値早見]({{ '/learn/quick-reference/' | relative_url }}) です。呼びごとの減衰の概数は [ケーブルの種類]({{ '/learn/cable-types/' | relative_url }}) です。dB/m の読み方と、長さ・周波数の計算例は [同軸ケーブルの損失]({{ '/learn/cable-loss/' | relative_url }}) です。高い周波数で別のモードが立つと、反射の読みも乱れます。その上限の入口は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。大きさと位相を円の上で見る入口は [第12話]({{ '/manga/12-smith-chart/' | relative_url }}) です。会話はフィクション演出です。

## 反射係数

特性インピーダンスが途中で変わると、進んできた波の一部が戻ります。境目は、オームの違うものをつなぐ点、コネクタの界面、端末の寸法の乱れ、負荷が線路と合わない点です。戻る波を、入射した波との比で書いたものが反射係数です。

Microwaves101 は、負荷のインピーダンスを ZL、線路の特性インピーダンスを Z0 として、次のように書いています。

Γ = (ZL − Z0) / (ZL + Z0)

Γ は大きさと角度を持ちます。角度は、戻る波の位相です。成績表の VSWR やリターンロスが使うのは、大きさだけです。このページでは、その絶対値を &#124;Γ&#124; と書きます。[深掘り]({{ '/learn/master/' | relative_url }}) と [数値早見]({{ '/learn/quick-reference/' | relative_url }}) は、この絶対値の側を Γ と置いています。同じ大きさです。取り違えないでください。

&#124;Γ&#124; は 0 から 1 のあいだを取ります。0 は戻らないこと、1 は全部戻ることに相当します。負荷が Z0 と一致すると、Γ は 0 です。第12話の円では、中心がこの 0、縁が大きさ 1 です。

Keysight は、反射係数 ρ を、反射した電圧の波と入射した電圧の波の比、と書いています。資料によっては、同じ絶対値を ρ や &#124;S11&#124; と書きます。

## VSWR

入射した波と、反射して戻った波が重なると、電圧の大きいところと小さいところができます。その最大と最小の比が、電圧定在波比（VSWR）です。1.0 が、反射が無いことに相当します。大きいほど、反射が多い、と読みます。

Keysight は、SWR を定在波の最大電圧と最小電圧の比とし、反射係数から次の形で求まる、と書いています。このページの記号では、次です。

VSWR = (1 + &#124;Γ&#124;) / (1 − &#124;Γ&#124;)

&#124;Γ&#124; が 1 に近づくと、分母が 0 に近づき、VSWR は限りなく大きくなります。

向きを逆にすると、次です。換算表は、こちらから計算しています。

&#124;Γ&#124; = (VSWR − 1) / (VSWR + 1)

## リターンロス

反射の大きさをデシベルで書いたものがリターンロスです。数字が大きいほど、反射は小さいです。20 dB は 10 dB より反射が小さい、という向きです。

Keysight は、反射した信号が入射した信号より何 dB 低いか、として RL = −20 log ρ と書いています。ここでの log は、デシベルの定義に合わせて 10 を底にします。

リターンロス（dB）= −20 log10(&#124;Γ&#124;)

VSWR が 1 のとき &#124;Γ&#124; は 0 で、対数は定義できず、リターンロスは無限大に相当します。表には入れていません。

Microwaves101 は、正しい形のリターンロスは正の数になる、と書いています。成績表が S11 を負の dB で書いているときは、符号を除いた大きさが、このページのリターンロスに対応します。欄名を確認してください。

## 反射する電力の割合

電圧の比が &#124;Γ&#124; のとき、同じ基準インピーダンスでは、電力の比はその二乗です。Microwaves101 は、&#124;Γ&#124; の二乗が反射した波の電力にあたる、と書いています。入射した電力を 1 とすると、戻る割合は &#124;Γ&#124;² です。

同じことをデシベルで書くと、リターンロス = −10 log10(&#124;Γ&#124;²) です。−10 log10(&#124;Γ&#124;²) は −20 log10(&#124;Γ&#124;) と等しいので、上の式と一致します。

たとえば &#124;Γ&#124; が 0.2 のとき、反射電力の割合は 0.04、つまり入射電力の 4% です。このときの VSWR は 1.50、リターンロスは 13.98 dB です。戻らなかった分が、すべて先の負荷へ届く、とは限りません。ケーブルの中で熱になる分は、次の挿入損失の側です。

## 挿入損失

挿入損失は、アッセンブリを経路に入れたことで、先へ届く信号がどれだけ減るかです。Rohde & Schwarz は、同軸ケーブルが信号を弱めることをケーブル損失、または挿入損失と呼び、長さと周波数の関数である、と書いています。両端を計測器につないだ透過の測定（S21）として読むことが多い、とも書いています。

長さについては、同資料は、損失の dB が長さに比例して増え、長さが 2 倍なら損失も 2 倍になる、としています。データシートは、多くの場合、1 m あたり、または 100 ft あたりの dB で書きます。使う周波数の行を見て、アッセンブリの長さを掛けます。温度や、反射をどう仮定しているかは、そのシートの条件を見ます。

周波数については、同資料は、関係は単純な直線ではなく、高い周波数の方が損失が大きくなりやすい、と書いています。増え方の入口は、導体と誘電体です。Analog Devices は、電流が導体の表面近くを流れることによる損失（表皮効果）が低い周波数側で目立ち、誘電体の損失が高い周波数側で目立つ、と整理しています。表皮効果の側は、単位長さの抵抗が周波数の平方根とともに増える、とも書いています。係数は、ケーブルの構造と材料で違います。dB/m の読み方、長さと周波数の計算例、コネクタを dB で足す手順は [同軸ケーブルの損失]({{ '/learn/cable-loss/' | relative_url }}) です。このページは、反射との切り分けにとどめます。言葉の短さは [用語集の表皮効果]({{ '/glossary/' | relative_url }}#skin-effect) です。

具体的な dB は、各メーカーのデータシートで確認してください。このページには、特定のケーブルの減衰表を置きません。呼びごとの学習用の概数を、どのシートからどう読んだかは [ケーブルの種類]({{ '/learn/cable-types/' | relative_url }}) にあります。そちらも、製品の保証値ではありません。

組み上がったアッセンブリの挿入損失は、ケーブル単体の減衰に、両端のコネクタと端末の工作が加わります。検査の項目のどこにこの数字を置くかは [アッセンブリの構造と製作工程]({{ '/learn/assembly-basics/' | relative_url }})、どう測るかの概略は [検査と測定]({{ '/learn/assembly-testing/' | relative_url }}) です。Rohde & Schwarz は、コネクタ、曲げ、損傷などの不連続がエネルギーを反射し、測定される損失をさらに増やすことがある、と書いています。成績表の挿入損失は、その一本を測った値を見てください。

反射が小さくても、ケーブルが長ければ、周波数が高ければ、挿入損失は増えます。短いケーブルでも、端末が乱れていれば反射は悪くなります。二つの数字を、一つの良し悪しにまとめないでください。切り分けは [深掘り]({{ '/learn/master/' | relative_url }}) にもあります。導通があることと、高周波で反射が小さいことは別です。計測器の入口は [数値早見]({{ '/learn/quick-reference/' | relative_url }}) のベクトルネットワークアナライザの節です。

## 成績表での向き

次の向きで読みます。

- VSWR は、1 に近いほど反射が小さいです。
- リターンロスは、dB が大きいほど反射が小さいです。負の dB で書いてある欄は、符号の向きを確認します。
- 挿入損失を正の dB で「損失」と書いてあるとき、数字が小さいほど、先へ届く信号の減りが小さいです。S21 を負の dB で書いてあるときは、0 dB に近いほど減りが小さいです。
- VSWR が良くても、挿入損失が小さいとは限りません。

系列ごとの周波数の目安は [コネクタの種類]({{ '/learn/connector-types/' | relative_url }}) です。
