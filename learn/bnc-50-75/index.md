# BNCコネクタの50Ωと75Ωの違いと見分け方

BNC は、二本のスタッドで留めるバヨネットの同軸コネクタです。同じ名前の系列に、50 Ω と 75 Ω があります。結合の形は近く、現行の規格では嵌合ピンの径の行も同じ幅です。特性インピーダンスの指定は違います。差さること、反射が残らないこと、規格の外側のピンでも相手を傷めないことは、別です。

ここにある数字は、公開の規格のプレビューと、メーカーの製品案内から取った学習用の目安です。個別の製品が保証する値ではありません。同じ系列でも、資料が複数の周波数を置きます。平均して一つの上限にはしません。

径と比誘電率の式、50 Ω と 75 Ω を一つの境目でつないだときの 0.2 は [特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) です。その 0.2 を VSWR やリターンロスへ入れる電卓は [電卓]({{ '/learn/calculator/#reflect' | relative_url }}) です。反射の読み方は [VSWR とリターンロス]({{ '/learn/vswr-return-loss/' | relative_url }}) です。系列の結合と周波数の早見は [コネクタの種類]({{ '/learn/connector-types/' | relative_url }})、4 GHz と 10 GHz と 11 GHz を一つの上限にしない読み方は [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。同じ 50 Ω のまま界面のピン径が資料で違う例は [SMA・3.5 mm・2.92 mm の互換]({{ '/learn/sma-35-292-compat/' | relative_url }}) です。名前の展開は [第10話]({{ '/manga/10-bnc-name/' | relative_url }}) です。会話はフィクション演出で、発明者とは断定しません。

外導体内径の 6.5 mm は、二つの規格の題が置く呼びです。界面の表の公差として、このページが読み直した数字ではありません。嵌合径の d は、それぞれの公開プレビューのピン側の表です。図面は転載していません。周波数の行は、下の節で資料ごとに分けます。4 と 10 と 11、1 と 4 を、一つの上限にはしません。

## 特性インピーダンス

同軸の特性インピーダンスは、内導体の外径、外導体の内径、誘電体の比誘電率で決まります。式は [特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) です。金属の嵌合寸法が揃っていても、誘電体の入り方と材料で、線路として見たオームは変わります。

IEC 61169-8:2007 の題は、特性インピーダンス 50 Ω の BNC です。IEC 61169-63:2020 の題は、特性インピーダンス 75 Ω の BNC75 です。どちらも、外導体の内径の呼びを 6.5 mm、結合をバヨネットとしています。ピンの嵌合径 d は、両方の表で 1.32 mm から 1.37 mm です。

75 Ω の表では、中心導体の径 m を 2.10–2.14 mm とし、75 Ω を満たすよう選び、製造者が指定する、と注が続きます。50 Ω の表の m は、公称 2.140 mm です。m を、嵌合ピンの d とは呼びません。d は、相手の受けに入る側の径です。

Connex は、国際的に標準化された BNC の嵌合面寸法の中では、完全な 75 Ω は実現できない、と書きます。1000 MHz までは、その小さなずれは実用上無視できる、とも書きます。同社が true 75 Ω と呼ぶものは、2000 MHz で VSWR の typical が 1.06:1 のもので、部品番号のあとにアスタリスクを付けて識別する、と書きます。標準の嵌合面に載せた 75 Ω と、その true 75 Ω を、一つの反射の成績にはまとめません。

Amphenol の 75 Ω は、型を二つに分けます。Type 1（75 Ω BNC-T1）は、一定の 75 Ω で、低い VSWR を DC から 4 GHz まで、とします。Type 2（75 Ω BNC-T2）は、低い反射で使える範囲を DC から 1 GHz まで、とし、1 GHz を超える用途には Type 1 を勧めています。Connex の「完全な 75 Ω は実現できない」と、Amphenol の「一定の 75 Ω」は、別の資料の文です。一つの設計には読みません。

## 外観で、どこまで分かるか

バヨネットの外形が同じで、上の表の嵌合ピン径も同じ幅です。中心コンタクトが細いから 75 Ω、とは、この二つの規格の d からは読みません。Amphenol のカタログでは、50 Ω の界面寸法の呼びと、75 Ω の界面寸法の呼びの両方に、0.052/0.054 インチが読めます。インチに直した d と同じ側です。図面は転載していません。HUBER+SUHNER の 50 Ω のカタログでは、プラグの G が 1.32–1.37 mm です。メス側の同じ文字は別の寸法なので、ピン径としては読んでいません。

誘電体の見え方も、一つの規則にはなりません。50 Ω の IEC 61169-8 は、ソケットの寸法 r（最大 6.50 mm）を、誘電体が基準面を超えて伸びる場合にだけ適用する、と注記します。75 Ω の IEC 61169-63 も、同じ r の最大 6.50 mm を、同じ条件で書きます。75 Ω のピン側の注は、座ぐりのない誘電体支持の端と、座ぐりがあるときの寸法を分けます。白い樹脂が合わせ面の近くまで入ることも、奥にあることも、規格の文の中に両方の余地があります。色の指定は、このページで読んだ範囲にはありません。

樹脂が見えること、見えないこと、ピンが太く見えることだけでは、50 Ω か 75 Ω かは決まりません。部品番号、刻印、データシートで分けます。Connex の true 75 Ω は、上のとおりアスタリスクです。規格の表を、規格の外の古い個体の寸法には使いません。このページは、1978年の IEC 60169-8 より前のピン径を、当時の本文から読んでいません。

## 混ぜたとき

### 機械的には、嵌合しうる

Rosenberger の製品案内は、50 Ω と 75 Ω が相互に嵌合する、と書きます。界面の案内は、どちらも IEC 61169-8、MIL-PRF-39012、CECC 22120 です。75 Ω 専用の別番号として IEC 61169-63 を、その案内は挙げていません。番号の世代は、このページでは決めません。

Amphenol のカタログは、50 Ω と 75 Ω を相互に嵌合でき、非破壊の嵌合のためである、と書きます。75 Ω の Type 1 と Type 2 は、互いとも、50 Ω とも嵌合する、と続きます。HUBER+SUHNER の 50 Ω のカタログは、50 Ω の BNC と 75 Ω の BNC は制限なく相互嵌合する、と書きます。Connex も、制限なく相互嵌合する、と書きます。

嵌合できることを、電気的に同じ系統だ、とは読みません。Amphenol の FAQ は、50 Ω のコネクタが 75 Ω のコネクタと物理的に嵌合しても、インピーダンスを混ぜることは勧めない、と書きます。

### 反射と VSWR

実数の一つの境目で 50 Ω と 75 Ω をつなぐとき、入射側から見た電圧の反射係数の絶対値は、次です。式は [特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) と同じで、Microwaves101 が Γ = (ZL − Z0) / (ZL + Z0) と書く形です。

&#124;Γ&#124; = &#124;75 − 50&#124; / &#124;75 + 50&#124; = 0.2

向きを逆にしても、絶対値は同じです。VSWR とリターンロスは、同ページの式から次になります。

VSWR = (1 + 0.2) / (1 − 0.2) = 1.50

リターンロス = −20 log10(0.2) = 13.98 dB

電力の比は &#124;Γ&#124; の二乗で、0.04、つまり入射電力の 4% です。欄へ 0.2 や 1.50 を入れて確かめるなら [電卓]({{ '/learn/calculator/#reflect' | relative_url }}) です。換算の表は [VSWR とリターンロス]({{ '/learn/vswr-return-loss/' | relative_url }}) です。

この 1.50 と 13.98 dB は、理想化した一つの境目の計算です。BNC のカタログがコネクタ自身に書く VSWR ではありません。Amphenol の 50 Ω は、M39012 のストレートで 0–4 GHz の最大 1.3、と書きます。75 Ω の Type 1 は 1.5 + 0.1×f（f は GHz）で DC から 4 GHz、Type 2 は 1.00 + 0.25×f で DC から 1 GHz、と書きます。1.3 や、周波数の入る式を、上の 1.50 へ平均しません。

境目の計算は、周波数を含みません。コネクタは長さを持つので、その境目が測定にどれだけ見えるかは、周波数で変わります。Connex は、嵌合面の中の小さなずれを、1000 MHz までは実用上無視できる、と書きます。Amphenol の FAQ は、混ぜたときの反射と VSWR の増加、信号の劣化は、高い周波数と長いケーブルでより大きい、と書きます。0.2 を、すべての周波数で測った BNC の値には読みません。

形だけを合わせた変換では、この不整合が測定に残ります。50 Ω の測定器で 75 Ω を測るときの最小損失パッドの例は、[特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) に出典つきで置いてあります。

### 機械的な損傷のおそれ

確認できた BNC の資料は、規格の内側の 50 Ω と 75 Ω を、壊さずに嵌合できる側へ置きます。Amphenol の語は nondestructive mating です。HUBER+SUHNER と Connex の語は、制限なく相互嵌合する、です。受けの接触を広げる、という警告は、このページで読んだ BNC の規格とカタログにはありません。

ゲージも、同じピンを想定しています。IEC 61169-8 と IEC 61169-63 のソケット用ゲージピンは、寸法用が 1.372–1.377 mm、保持力の測定用が 1.308–1.321 mm です。幅は二つの規格で揃います。

その文は、規格の内側の界面の話です。曲がったピン、1.37 mm を超えて太いピン、摩耗した受けは、外です。その個体が 50 Ω の名前だから太い、とは読みません。規格の外の古いピン径は、上のとおり、このページでは本文から読んでいません。

N 型は別です。IEC 61169-16 は、75 Ω の N を強く非推奨とし、50 Ω と誤って嵌合すると 75 Ω 側を壊しうる、と書きます。BNC の「非破壊」を、N 型へ写しません。N 型の注意は [コネクタの種類]({{ '/learn/connector-types/' | relative_url }}) です。同じ 50 Ω でも、SMA のピンが 3.5 mm や 2.92 mm の受けを傷めうる話は [SMA・3.5 mm・2.92 mm の互換]({{ '/learn/sma-35-292-compat/' | relative_url }}) です。系列が違います。

## 用途の違い

Amphenol のカタログ冒頭の用途一覧は、アンテナ、基地局、計測器、ネットワークアナライザ、オシロスコープ、無線、通信を BNC の用途に置き、放送だけを（75 Ω）と括弧で分けます。50 Ω の節は、コンピュータと LAN、試験と計測、医療機器、通信、無線とネットワークを挙げます。75 Ω の節は、放送と CATV で使う 75 Ω ケーブル向けとし、放送、衛星テレビの地球局、通信、HDTV を挙げます。オシロスコープの入力が常に 50 Ω だとは、その一覧は書いていません。機器の指定を見ます。

Rosenberger の製品案内は、実験室、データシステム、通信に使う、とシリーズ全体に書きます。50 Ω 専用、75 Ω 専用とは、その文は分けていません。周波数の行は分けています。50 Ω は最大 DC–10 GHz、最適 DC–4 GHz です。75 Ω は最大 DC–4 GHz、最適 DC–1 GHz です。

HUBER+SUHNER の 50 Ω のカタログは、界面の周波数を DC から 4 GHz まで、とします。Amphenol の 50 Ω は、11 GHz まで動作し、低い反射は 4 GHz まで、と書きます。10 と 11 と 4 を、一つの上限にはしません。読み分けは [使用周波数の上限]({{ '/learn/frequency-limit/' | relative_url }}) です。

映像のシリアルデジタルで、75 Ω の負荷を使う、という資料の置き場所は [特性インピーダンス]({{ '/learn/impedance/' | relative_url }}) です。宅内のねじ結合の 75 Ω は F 型です。BNC のバヨネットとは別の系列です。分けは [コネクタの種類]({{ '/learn/connector-types/' | relative_url }}) です。

## 対応するケーブル

コネクタのオームと、ケーブルのオームは、別の指定です。Amphenol の BNC は、終端するケーブルの例に RG-58、RG-59、RG-179、RG-316 を挙げます。その一文は、各ケーブルのオームを決めてはいません。オームは、ケーブルの仕様書の題と、製品のデータシートで見ます。

<div class="table-scroll" markdown="1">

| 呼び | インピーダンスの出典 | メモ |
| --- | --- | --- |
| RG-58（M17/28-RG058） | 仕様書一覧の題は 50 Ω。Times Microwave の整理表は 50 ±2 Ω | 50 Ω の汎用フレキシブル。詳細は [ケーブルの種類]({{ '/learn/cable-types/' | relative_url }}) |
| RG-316（M17/113-RG316） | 仕様書一覧の題は 50 Ω | より細い 50 Ω。Amphenol の終端例に挙がる |
| RG-59（M17/29-RG59） | 仕様書一覧の題は 75 Ω | Belden 8241B は RG Type 59、公称 75 Ω。同社はアナログ映像用、と書く |
| RG-179（M17/94-RG179） | 仕様書一覧の題は 75 Ω | 細い 75 Ω。Amphenol の終端例に挙がる |
| RG-6（M17/2-RG6） | 仕様書一覧の題は 75 Ω | 75 Ω のケーブルの呼び。端のコネクタが BNC とは、この題は書いていない |

</div>

RG の番号は、同じ呼びでも中心導体や外被が分かれることがあります。一覧の題のオームを、市販のすべての RG-59 の保証値には読みません。Belden 8241B は、その製品の公称値です。M17/28 の ±2 Ω は、Times Microwave が整理した行です。仕様書本文の公差表は、このページでは開いていません。

75 Ω の映像ケーブルの別の例は、[シールド]({{ '/learn/shielding/' | relative_url }}) に置いた Belden 1694A です。RG 番号ではありません。
