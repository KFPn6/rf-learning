# 読む

公開してよいノートや記事へのリンクを置く場所です。いまはプレースホルダで、紹介している記事はまだありません。

## 足し方

`reading/index.md` の「リンク」に、次の形で一行足します。

```
- [記事の題名](https://example.com/note) — 何が読めるかを一文で
```

`example.com` は記入例です。実在の記事として掲載しているわけではありません。足したあとは、通常の更新と同じようにリポジトリへ反映します。直し方はリポジトリの README にあります。

## リンク

- まだありません。

## 置くもの、置かないもの

置くのは、規格の解説、測定の入門、用語の補足など、すでに公開されているものです。置かないのは、非公開の図面、価格、社内の運営メモです。運営側の計測と目標は、サイトのページではなくリポジトリの `docs/METRICS.md` にあります。

周波数の見取り図そのものは [規格・周波数]({{ '/spectrum/' | relative_url }})、言葉は [用語集]({{ '/glossary/' | relative_url }}) にあります。リンクが増えても、この二ページの代わりにはしません。一次情報への案内として足していきます。
